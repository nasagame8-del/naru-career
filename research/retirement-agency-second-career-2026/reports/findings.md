## 1. 退職代行サービスは本当に減っているのか？

### 事実

- 書面で確認できた**倒産は1件のみ**。株式会社スマートヤメマス、破産手続開始決定 2026-03-25、東京地裁、負債約500万円（東京商工リサーチ）。

- **運営企業自身によるサービス終了告知は0件**。58件すべてを検索したが、公式の終了アナウンスは1件も見つからなかった。
- **法人番号公表サイトで登記記録の閉鎖が確認された法人は0件**（照合できた24法人すべて）。スマートヤメマスも破産決定後も登記は閉鎖されていない。
- 一方で、**サイトに到達できないが倒産を確認できないサービスが8件**ある。観測内容は次のとおり。

| リーガルジャパン | 公式ドメインが名前解決不能 |
| 退職代行トリケシ | 公式ドメインが名前解決不能 |
| ベンゴシNOW | 公式ドメインが名前解決不能 |
| 退職代行だいじょうぶ | 公式ドメインが名前解決不能 |
| 退職代行スマートヤメマス | 公式ドメインが名前解決不能（唯一、破産も確認済み） |

LPのサブドメインだけが消えて本体サイトは生きているケースを「消滅」と誤計上しないよう、

2年10か月で確認できた倒産は1件、負債約500万円である。

起きているのは倒産ではなく**確認不能化**である。サイトが消え、ドメインが失効し、
連絡経路が切れる。しかし法人は登記上存続し、倒産も終了告知もない。
したがって「何社潰れたか」は、この市場の実態を測る指標として機能していない。

## 2. どんなサービスが市場から消えているのか？

### 事実

非継続9件のうち、属性が判明しているのは限られる。

- 価格帯が判明しているのは**1件のみ**（非継続9件中）。残り8件は価格を取得できていない。
- 運営形態が判明しているものは**0件**。運営形態は到達可能なサイトからしか読めないため、消えたサービスの運営形態は原理的に取得できていない。
- 2025年のアーカイブから訴求内容を復元できたのは一部のみ。

### 解釈

**「どんなサービスが消えたか」は、本調査では答えられない。**

これは結論ではなく観測の限界である。属性（運営形態・価格・機能）はサイトが生きている間しか読めないため、
属性が分かっているサービスは定義上すべて生存者になる。この構造的な生存バイアスを解消できていない。

アーカイブから最終観測価格を復元して部分的に補ったが、非継続側で価格帯が分かるのは1件にとどまり、
価格と継続の関係を論じられる水準には達しなかった。

**「安いサービスから潰れた」という説明を本データで裏づけることはできない。**
裏づけられないことを、裏づけられたように書いてはならない。

## 4. 料金競争は起きているのか？

### 事実

同一サービス内で2024年と2026年の正社員価格を比較できたのは**10件**。

| 変化 | 件数 |
|---|---|
| 下落 | 3 |
| 変化なし | 5 |
| 上昇 | 2 |

中央値は 22,000円 → 20,900円（約5%下落）。

個別の動き:

- 退職代行EXIT 20,000円 → 15,000円
- 退職代行ネルサポ 22,000円 → 15,000円
- 退職代行やめたらええねん 22,000円 → 19,800円
- 退職あんしん代行 2,980円 → 12,980円（上昇）
- 退職代行だいじょうぶ 14,800円 → 19,800円（上昇。その後サイト消滅）

### 解釈

**「価格競争が激化している」とは言えない。**比較できた10件のうち過半の5件は価格が動いていない。
中央値は下がったが、下落3件・上昇2件であり、方向が揃っていない。

母集団全体の平均価格の年次比較は行っていない。停止したサービスが母集団から抜けるため、
生存バイアスで価格が上がったように見えてしまうからである。

なお帝国データバンクは平均価格が約29,410円（2025年）から約27,000円（2026年）へ下落したと公表しているが、
これは同社の母集団に対する平均であり、本調査の10件の同一サービス比較とは別の測定である。

## 6. 「辞めるだけ」から「退職後まで支援」へ市場は変化しているか？

### 事実

2024年・2025年のアーカイブ42件と現在を比較した結果、変化は**一方向ではなかった**。

追加した例:

- **退職あんしん代行**: 2024年はキャリアアップ相談のみ → 2025年に転職先紹介・キャリア相談・失業給付サポートを揃え、現在も維持
- **退職代行ネルサポ**: 2024・2025年はキャリア相談なし → 現在は提供
- **退職代行だいじょうぶ**: 2025年に無料転職支援を追加（最短1週間で内定・書類添削・転職成功で全額キャッシュバック）→ **2026年にサイト消滅**

撤退した例:

- **退職代行ヤメドキ**: 2024年なし → 2025年に「転職サポート事業」を事業内容に記載 → **現在は再び記載なし**。失業給付サポートも同様に撤退
- **退職代行モームリ**: 2024年は「失業保険・社会保険給付金サポートの完備」 → **現在は記載なし**

### 解釈

**「辞めるだけ」から「退職後まで」への一方向の進化は起きていない。**
追加する動きと撤退する動きが同時に存在する。

最も踏み込んだ退職後支援を構築しただいじょうぶは、その直後に市場から消えた。
退職後支援の充実が生存を保証しないことを示す例だが、n=1であり因果は論じられない。

## 7. 転職支援を行う退職代行はどれくらい存在するか？

### 事実

退職後支援の有無を公式サイトで判定できた**32件**が分母。

| career_support_type | 件数 | 判定済32件に対する割合 |
|---|---|---|
| NONE（退職完了で終了） | 17 | 53.1% |
| PARTNER_REFERRAL（提携先へ送客） | 9 | 28.1% |
| CAREER_COUNSELING（キャリア相談） | 3 | 9.4% |
| JOB_PLACEMENT（自社で求人紹介） | 3 | 9.4% |
| INFORMATION_ONLY | 0 | 0% |
| UNKNOWN（訴求はあるが仕組み不明、または未調査） | 26 | — |

- 何らかの退職後支援を持つのは **15 / 32件（46.9%）**
- **自社で求人紹介まで行うのは3件のみ**: 退職代行モームリ、退職代行EXIT、退職あんしん代行

### 解釈

**退職後の支援を掲げるサービスは半数弱あるが、その多くは自社では行わない。**
「転職サポートあり」の実体は、提携エージェントへの送客（9件）が最多である。

送客自体は悪いことではない。ただし読者の期待と実体にはずれが生じやすい。
「転職サポート付き」という表示から、求人紹介や面接対策まで自社で面倒を見てくれると読むと外れる。

さらに、支援を謳いながら中身が確認できないケースがあった。
退職代行みらいは転職支援サービスを広告しているが、該当ページ自体が「Coming soon・・・」であり、
フッターの電話番号もダミーの `03-1234-5678` のままだった。

EXITは自社で求人検索・履歴書作成・応募〜面接日程調整まで行うが、
「面接以外を全て代行」と明記しており、面接そのものは支援範囲外である。

## 9. 第二新卒が退職代行を使った場合、どんな問題がサービス外に残るのか？

### 事実

判定できた35件について、第二新卒が退職後に直面しうる論点への言及を確認した。

| 論点 | 言及あり / 判定済 | 判定済に対する割合 |
|---|---|---|
| 退職後サポート全般の訴求 | 22 / 35 | 62.9% |
| 失業給付の案内 | 12 / 35 | 34.3% |
| 提携エージェントへの送客 | 9 / 33 | 27.3% |
| 求人紹介の訴求 | 7 / 33 | 21.2% |
| キャリア相談 | 7 / 29 | 24.1% |
| 職務経歴書・履歴書の支援 | 4 / 28 | 14.3% |
| 面接対策の支援 | 3 / 28 | 10.7% |

ここで注意が必要な差がある。

- 「退職後サポート」を訴求するのは **22 / 35件（62.9%）** だが、
  退職後の**キャリア**支援を持つと分類できたのは **15 / 32件（46.9%）**、
  自社で求人紹介まで行うのは **3件** である。
- 「求人紹介」の文言がある7件に対し、`career_support_type = JOB_PLACEMENT` と分類したのは3件。
  差の4件は、文言はあるが仕組みの記載がないか、提携先経由であることが読み取れたもの。

つまり「退職後サポート」という表示の多くは、**キャリアではなく手続き**（離職票・保険・私物返却など）を指している。

一方、以下については体系的な言及を確認できなかった。

- 退職理由を次の面接でどう説明するか
- 短期離職をどう説明するか
- 空白期間の扱い
- 次の会社をどう選ぶか（同じ失敗を避ける方法）
- 辞める時期の判断（次が決まる前か後か）

### 解釈

退職代行が引き受けるのは**退職の実行**である。
引き受けないのは**退職の意味づけと次の選択**である。

第二新卒が退職代行を使った後に残るのは、おおむね次の問いになる。

1. 前職を1〜3年で辞めた理由を、次の面接でどう説明するか
2. 書くことの少ない職務経歴書をどう組み立てるか
3. 同じ理由で辞めることにならない会社を、求人票のどこで見分けるか
4. 辞めてから探すのか、探してから辞めるのか

退職代行はこれらを解かない。業務範囲外だからである。
弁護士法人であれば職域外、民間であれば提携先の領域になる。

## 10. 「退職しやすくなったこと」と「より良い転職ができること」は同じなのか？

### 事実として言えること

- 退職の実行を代行するサービスは、2026年10月時点で少なくとも44件が稼働している（母集団58件、判定済53件）。
- そのうち、次の転職までを自社で担うのは3件である（退職後支援を判定できた32件中）。
- 「第二新卒」を対象として明示するサービスは、現在も2024年・2025年を通じて0件である。

### 解釈として言えること

**同じではない。** 供給の構成がそれを示している。

辞める手段は豊富に供給されている。価格は1.5万円前後から選べ、
即日対応・LINE相談・返金保証といった機能で横並びに競争している。
退職という行為は、外部サービスへ発注できる手続きとしてほぼ完全にコモディティ化している。

一方で、次の会社を選ぶ部分は、この市場のほぼ外側にある。
自社で求人紹介まで行う3件を除けば、提携先への送客か、何もないかである。
そして第二新卒という属性は、どのサービスの訴求にも現れない。

### ここから先は本調査では言えないこと

「退職代行を使った第二新卒の転職が実際に不利になるか」は測っていない。
本調査が観測したのは**供給側の構成**だけであり、利用者の転職結果は追跡していない。

供給の偏りから需要側の困難を断定することはしない。
「退職代行があるから辞めやすくなった」も因果としては示せていない。
退職代行の普及と早期離職の増減の関係は、本調査の範囲外である。

## 11. 外部調査との比較

NARU独自母集団を先に構築したうえで、最後に比較する。数値を合わせる調整は行っていない。

| | NARU独自調査 | 帝国データバンク |
|---|---|---|
| 対象 | 58サービス | 52事業者 |
| 継続なしと判定 | 9件 | 14件 |
| 割合 | 17.0%（判定済53件に対して） | 26.9%（52件に対して） |
| 基準日 | 2026-10-07 | 2026-09 |
| 判定基準 | サイト応答・公式告知・裁判所情報。到達不能は停止扱いだが倒産ではない。判定材料不足はUNKNOWNとして分離 | 「通常の手段でサービス継続が確認できない状態」 |
| 判定不能を分離するか | する（5件） | 公表されていない |

### 差が出た理由

1. **母集団の作り方が違う。** NARUは比較サイト・運営形態別特集・PR TIMESの新規参入告知・退出イベントの4系統から独自に58件を構築した。TDBは自社企業データベースを起点に52件を定義している。NARUの母集団には2026年参入組（退職代行ヤメルート、AI退職代行 by 行政書士など）が含まれる。
2. **基準日が1か月違う。**
3. **判定不能の扱いが違う。** NARUは判定材料が足りない5件をUNKNOWNとして継続側にも停止側にも入れていない。この5件を全て停止に入れると 14/58 = 24.1% となり、TDBの26.9%に近づく。差の大きな部分は、判定不能をどう扱うかの違いで説明できる。
4. **TDBは14件の個別名を公表していない**ため、どのサービスが重複しているかは照合できない。

### 共通している点

両調査とも、**「継続が確認できない」ことを停止として数えている**。
倒産の確認ではない。TDBも同社の集計で実際の倒産は1件（スマートヤメマス）としている。

## 12. 情報環境についての付随的な発見

これは当初の調査項目ではないが、第二新卒読者にとって実務的な意味があるため記録する。

### 事実

- **比較サイトのランキングに、すでに到達不能なサービスが現役として掲載されている。** リーガルジャパンとトリケシはそれぞれ4つの比較サイトに掲載されているが、公式ドメインは名前解決できない。
- **逆に、稼働中のサービスが「運営停止」と表示されている例がある。** 辞めるんですは正常に稼働しているが、ある比較サイトは【運営停止】と表示していた。
- **消滅したサービスのドメインが第三者に転用されている。** 退職代行ニチローの `nichirou.com` は現在オンラインカジノのアフィリエイトサイトになっている。退職代行J-NEXTのドメインは「コンセプトカフェが人気の理由」という無関係な内容を配信している。
- **比較サイト間で運営形態の記述が矛盾している。** 母集団58件のうち31件で、情報源によって民間／労働組合運営／労働組合提携の記述が食い違っていた。例えば退職代行OITOMAは、あるサイトでは「労働組合が運営」、別のサイトでは「労働組合と提携」と書かれている。
- 公式サイト自身の記述と特商法の記載が食い違う例もある。OITOMAはサイト上で「労働組合が運営している」と表示するが、特商法の販売業者は株式会社H4である。
- **公式サイトを実地調査できた35件のうち14件で、特定商取引法に基づく表記ページを発見できなかった。**
- **特商法の記載住所が古いままの法人が3件あった。** 株式会社スムリエは2021年3月、株式会社スリープラスは2025年5月、弁護士法人みやびは2026年8月に移転済みの住所を掲載し続けている。いずれも登記の変更履歴に旧住所が残っていたため同一法人と確定できた。
- **本店移転が頻繁な法人がある。** 株式会社PULLBACKは2015年以降8回、株式会社アルバトロスは4年未満で6回、弁護士法人あおばは大阪↔広島を5回往復（直近は調査6日前の2026-10-01）。

### 解釈

退職代行を探す人がまず見るのは比較サイトである。
その比較サイトは、消滅したサービスを現役として載せ、稼働中のサービスを停止と書き、
運営形態を取り違えている。

退職代行の「選びにくさ」は、サービスの数や価格ではなく**情報の信頼性**にある可能性がある。
これは次の会社選びの難しさと構造が似ている。求人票から会社の実態を読み取る作業と、
比較サイトから退職代行の実態を読み取る作業は、同じ種類の困難である。

| H1 | 2024〜2025年の大量参入後、2026年に淘汰が進んでいる | **一部支持**。非継続9件を確認。ただし書面で確認できた退出は倒産1件のみで、残り8件は到達不能の観測。淘汰の実体は倒産ではなく確認不能化 |

## 14. 記事化にあたっての禁止事項

本調査のデータで**書いてはいけないこと**を明示する。

- 「退職代行が相次いで倒産している」— 確認できた倒産は1件
- 「安い退職代行から潰れた」— 価格と継続の関係は検証不能
- 「弁護士系は生き残り、民間系は消えた」— 運営形態別の継続率は生存バイアスの産物

- 母集団58件を分母にした割合を、判定できていない項目について作ること

逆に、**分母を付けて書けること**は `analysis/article-ready-metrics.json` に10指標を整理した。
