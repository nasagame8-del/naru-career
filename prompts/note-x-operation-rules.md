# note × X 運用ルール

note記事の公開後のX告知、およびnote読者とのエンゲージメント運用のルール。

---

## X告知ルール

- note記事を公開したら、**30分以内**にXで告知する
  - 初速を確保し、noteの「おすすめ」掲載アルゴリズムに乗りやすくするため
- 告知ツイートには、記事の核心・フックとなる**具体的な情報（数字・意外性のある一言）**を含める
  - 単なる「投稿しました」＋リンクだけの告知にしない

---

## スキ読者への選択的フォロバックルール

- 記事にスキをつけてくれた読者は、最もエンゲージメントの高い層として**選択的にフォロバック**する
- **無差別フォローはしない**
  - 過去に「無差別フォローはペナルティリスク・低エンゲージメント」という判断で不採用にした方針を維持

---

## 記事末尾の「次回予告＋フォロー誘導」ルール

- **背景**: 記事が読まれているのにフォローに繋がらない問題への対策（2026年7月24日、外部リサーチを踏まえて決定）
- note記事の末尾（ハッシュタグの直前）に、**次回予告＋フォローのメリット**を一言添える
- 形式例:
  ```
  明日は「◯◯」について書きます。フォローしてもらえると届きます。
  ```
  ```
  次回は◯◯の話です。フォローすると更新が届くので、気になる方はぜひ。
  ```
- **空手形にしない**: 予告の内容は、実際に投稿予定のテーマと矛盾しないよう、articles-status.jsonのscheduled_publishやnote-draftsの準備状況と照合してから書く。「明日」と書いたら翌日に投稿できる状態であることを確認する
- 予告テーマが未定の場合は、具体的なタイトルではなく方向性（「転職活動の実体験シリーズ、続きます」等）で濁してよい
