# note × X 運用ルール

note記事の公開後のX告知、およびnote読者とのエンゲージメント運用のルール。

---

## X告知ルール

- note記事を公開したら、**30分以内**にXで告知する
  - 初速を確保し、noteの「おすすめ」掲載アルゴリズムに乗りやすくするため
- 告知ツイートには、記事の核心・フックとなる**具体的な情報（数字・意外性のある一言）**を含める
  - 単なる「投稿しました」＋リンクだけの告知にしない

---

## スキ読者への選択的フォロバックルール

- 記事にスキをつけてくれた読者は、最もエンゲージメントの高い層として**選択的にフォロバック**する
- **無差別フォローはしない**
  - 過去に「無差別フォローはペナルティリスク・低エンゲージメント」という判断で不採用にした方針を維持

---

## 記事末尾の「次回予告＋フォロー誘導」ルール

- **背景**: 記事が読まれているのにフォローに繋がらない問題への対策（2026年7月24日、外部リサーチを踏まえて決定）
- note記事の末尾（ハッシュタグの直前）に、**次回予告＋フォローのメリット**を一言添える
- 形式例:
  ```
  明日は「◯◯」について書きます。フォローしてもらえると届きます。
  ```
  ```
  次回は◯◯の話です。フォローすると更新が届くので、気になる方はぜひ。
  ```
- **空手形にしない**: 予告の内容は、実際に投稿予定のテーマと矛盾しないよう、articles-status.jsonのscheduled_publishやnote-draftsの準備状況と照合してから書く。「明日」と書いたら翌日に投稿できる状態であることを確認する
- 予告テーマが未定の場合は、具体的なタイトルではなく方向性（「転職活動の実体験シリーズ、続きます」等）で濁してよい

---

## タイトルパターン集

note記事のタイトルに使えるフック型の一覧。全記事に**数字・意外性・ギャップ**のいずれかを含めるルール（controversial-post-rules.md）は維持しつつ、以下のパターンを引き出しとして活用する。

### パターン1：数字・意外性・ギャップ型（基本、全記事必須）

- controversial-post-rules.md の「タイトルのフック要素」参照
- 例：「入社3ヶ月で辞めたいと思うのは異常なのか」「何度も消しては書き直した。職務経歴書と向き合っていた頃の話」

### パターン2：「認知的な隙間」型（2026年7月26日追加）

一見つながらない2つの要素（状況＋意外な行動・場所等）を並置し、「なぜ？」という好奇心を意図的に作るタイトル。内容を明かしすぎず、クリックしないと分からない余白を残す。

**型の構造：**
- `[通常予想される行動] ではなく [意外な要素]`
- `[状況] のとき、僕は [意外な場所・行動] にいた/した`

**良い例：**
- 「転職を決める前、僕がやったのは面接対策ではなく『京都』だった」
- 「転職を決めたあの夏、僕は『京都』にいた」

**使用条件（誠実さを保つ制約）：**
1. 「意外な要素」は必ず**実話**であること（experience-notes.mdに記録がある、または本人確認済み）。インパクトのための誇張・捏造はしない
2. タイトルの意味合いの強さは、実際の体験の重みと**釣り合っていること**。息抜き程度の体験を「人生が変わった瞬間」のように過大演出しない
3. 本文冒頭で、タイトルの「意味」を**早めに明かす**（QCEP形式のQ部分で種明かし）。引っ張りすぎて読者が離脱しないようにする
4. 毎回使うものではない。実話の中に「一見つながらない2要素」が実際に存在する場合にのみ使用し、**無理にこじつけない**

**位置づけ：**
- 既存フック（数字・意外性・ギャップ）と併用可能
- 特に**通常回（実体験レポート型）**のタイトルに新しい引き出しとして有効
- 賛否両論型にも使えるが、問いかけ型との組み合わせで使う
