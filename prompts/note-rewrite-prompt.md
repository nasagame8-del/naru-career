# note版リライトプロンプト

以下の自社サイト記事をnote用にリライトしてください。

## 入力情報
- 元記事: {{article_content}}

## リライトルール（厳守）
1. 完全コピペ禁止。同じ内容でも文章を書き直す
2. 視点の変換：
   - 自社サイトが「ガイド型」（〜の方法、〜の手順）→ noteは「体験記型」（僕が〜した話）
   - 自社サイトが「比較型」（〜おすすめ5選）→ noteは「意見型」（僕が〜を選んだ理由）
3. note版はよりカジュアルに、語りかけるトーンで書く
4. 実体験パート `[EXPERIENCE: ...]` はそのまま残す（人間が埋める）
5. 記事末尾に以下のリンクブロックを必ず入れる：

```
---
📝 詳しい比較や手順は、ブログ記事にまとめています。
👉 [記事タイトル](自社サイトURL)
```

6. 文字数：1500〜2500文字程度（noteで読みやすい長さ）
7. note独自のh2/h3構造は不要。段落ベースで読みやすくする
8. 記事末尾（ハッシュタグの直前）に**次回予告＋フォロー誘導**を一言添える：
   - 例：「明日は◯◯について書きます。フォローしてもらえると届きます。」
   - 予告の内容は実際の投稿予定と矛盾しないこと（note-x-operation-rules.md参照）
   - テーマ未定の場合は方向性で濁してよい

## 感情・葛藤の描写ルール（2026年7月25日、実測データに基づき追加）

実測（全体489ビュー・スキ86・11記事）で、感情・葛藤・迷いを正直に書いた記事のスキ率が20〜37%台、単純な体験レポート（〜してみた、〜を比較した）は6〜10%台だった。「体験レポート型でもスキ率を上げる」ために、以下を必須とする。

1. **行動の前にあった不安・迷い**を必ず1箇所以上書く
   - NG：「ビズリーチに登録した。結果、スカウトが3件来た」
   - OK：「正直、第二新卒でビズリーチなんか使っていいのか不安だった。ハイクラス向けのイメージが強すぎて、場違いな気がしていた」
2. **やってみて感じた戸惑い・想定との違い**を必ず1箇所以上書く
3. **感情の変化を伴う結論**で締める（事実の羅列だけで終わらせない）
4. **タイトル・冒頭**は、読者が「自分と同じ状況だ」と感じられる具体的な感情描写（戸惑い、不安、情けなさ等）を優先する。結果や事実だけのタイトルは避ける
