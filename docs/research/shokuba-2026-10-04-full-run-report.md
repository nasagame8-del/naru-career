## 3. Stage 5（provisional）

**この節の数値はすべて `provisional: true`。記事の確定数値として使ってはいけない。**

成果物に記録されている理由:

> 1求人=1レコードの達成度が未完成のため、求人件数および求人単位の割合は暫定値。
> Golden Set 50ページでの precision は 0.97 だが recall は 0.47 で、一覧ページ側の求人を取りこぼす。

precision 0.97 / recall 0.47 という性質上、**抽出できた求人はほぼ本物だが、全体の半分以上を取りこぼしている**。
したがって「求人が何件ある」「○%が第二新卒歓迎」という方向の数字は過小評価になる。
