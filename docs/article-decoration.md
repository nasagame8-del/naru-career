# 記事装飾ガイド

記事の見出しと囲みの見た目は `src/app/globals.css` の共通CSSと `src/components/LabeledBox.tsx` が持っています。
**記事ごとのCSS・クラス指定は不要です。** 通常のMarkdownと既存のfrontmatterで書けば、同じ装飾が自動で付きます。

参考にした読みやすさの型: <https://www.xserver.ne.jp/blog/blog-easy-to-read/>

---

## 1. 見出し（自動）

Markdownの `##` `###` `####` をそのまま書くだけです。

| 記法 | 見た目 |
| --- | --- |
| `## 見出し` | ティーグリーン #1F6F66 のベタ塗りの帯。白の太字。左にアンバーの二重山形アイコン |
| `### 見出し` | 下線。左の一部だけティーグリーン、残りは淡い緑 |
| `#### 見出し` | 小さなアンバーの四角＋太字 |

```markdown
## 転職エージェントの選び方

### 求人数で選ぶ

#### 公開求人と非公開求人の違い
```

### 書くときの注意

- H2の二重山形アイコンはCSSの装飾です。**見出しテキスト・見出しID・目次・読み上げには入りません。** 見出しに `»` や記号を自分で書き足さないでください。
- 見出しIDは従来どおり本文側で `section-0`, `section-1`, … が自動採番されます。目次リンクも自動です。
- H2は長くても2行以上に折り返り、アイコンと文字は重なりません。帯の幅に合わせて見出しを削る必要はありません。
- 見出しの中にリンクを置くこともできますが、帯の上では白文字のままになります。

## 2. ラベル付き囲みボックス

淡い緑の囲みに、左上へ少し飛び出す濃い緑のラベルが付きます。

### 記法

````markdown
:::box 応募前に確認すること
- 職務内容が書面にあるか
- 試用期間中の条件が書いてあるか
:::
````

- 開始行は `:::box` ＋半角スペース ＋ ラベル。**行頭から**書きます。
- 終了行は `:::` だけ。
- ラベルは省略できます（`:::box` だけの行）。その場合はラベルなしの囲みになります。
- 中身は普通のMarkdownです。段落・箇条書き・番号付きリスト・太字・リンク・表が使えます。
- 箇条書き（`-`）の記号は、囲みの中ではティーグリーンのチェックになります。
- 番号付きリスト（`1.`）は番号のまま、ティーグリーンで表示されます。

### 使用例

````markdown
:::box この章のポイント
- 求人票の**雇用形態**と契約期間を先に見る
- 不明点は[問い合わせ窓口](/contact)で確認する
:::

:::box
ラベルなしでも使えます。補足を1段落だけ囲みたいときに。
:::
````

### 使うときのルール

- **必要な箇所にだけ使ってください。** 箇条書き・太字・段落を自動で囲む仕組みにはしていません。囲みが続くと帯見出しの区切りが効かなくなります。
- 1つのH2セクションに1つまでを目安にします。
- ラベルは短く。長くても欠けたり重なったりはせず折り返しますが、2行になると帯見出しとの差が弱まります。
- **入れ子にはできません。** `:::box` の中にもう1つ `:::box` は書けません。
- 囲みは「補足・チェックリスト・注意」の器です。引用（`>`）とFAQは別の見た目を持っているので、意味が違うものを囲みに寄せないでください。
- 既存の体験談ボックス `[EXPERIENCE: ...]` と比較表 `[COMPARISON_TABLE:id]` は従来どおりです。囲みへ置き換える必要はありません。

## 3. 記事冒頭の2つの囲み（frontmatterから自動）

本文には書きません。frontmatterを書けば、本文と同じ囲みの体系で表示されます。

| frontmatter | 表示 |
| --- | --- |
| `summary:` | 「この記事で分かること」。淡い緑の囲み＋チェックリスト |
| `naruPoint:` | 「この記事の要点」。クリーム色の落ち着いた囲み（`naru-box--quiet`） |

2つが並んでも過密にならないよう、要点側だけ背景とラベルを一段弱くしています。どちらもfrontmatterのキー名・値の形式は従来のままです。

## 4. 実装の場所

| 対象 | ファイル |
| --- | --- |
| 見出し・囲みのCSS | `src/app/globals.css`（`.prose h2/h3/h4`, `.naru-box`） |
| 囲みのReactコンポーネント | `src/components/LabeledBox.tsx` |
| `:::box` のMarkdown変換 | `src/lib/articles.ts` の `convertLabeledBoxes` |
| 変換のテスト | `src/lib/articles.test.ts`（「ラベル付き囲みボックス記法」） |

色はすべて `globals.css` の CSS変数（`--primary` `--primary-soft` `--amber` ほか）を参照しています。記事側で色を直接指定しないでください。
