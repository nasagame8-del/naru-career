## 実装

タイトル、質問、診断中、結果、ステータス詳細、16タイプ図鑑を実装。背景3種、羊皮紙、青金コマンド、看板、案内役、コンパス、水晶球、16種の大型結果キャラクターを独立画像として配置しました。文言・質問・ボタン・タブ・リンクはDOMです。全画面画像の貼り付けではありません。

質問20問、16タイプ判定、正式データ、CTA定義、計測定義は変更していません。結果の共有処理、タイプ詳細リンク、広告表記、SEOを維持。旧画像は削除せず、図鑑では既存の正式キャラクターを使用。ステータスは既存データを表示し、根拠のない能力値・レーダーチャートは追加していません。

1440px（高さ1000px）と390px（高さ844px）で6画面を撮影。ステータスと図鑑全体は要素全体の画像も用意しています。review.htmlから参照できます。

### 残る差分

- 背景は参照モックに合わせた新規生成画であり、城の建築・家具・地形・筆致の細部までのピクセル一致ではありません。
- 結果と図鑑の名称・キャラクターは正式16タイプに合わせています。モックの仮タイプ名やキャラクターそのものの転写ではありません。
- ロゴは不自然な画像内文字を避け、実テキストと独立コンパスで構成。羊皮紙の角金具・ボタンの縁形状には細部差があります。
- ステータスは正式データの文章・タグを表示。モックにあるレーダーは根拠がないため使用していません。
- スマホ図鑑は操作性のため2列、PCは4×4。縦方向のスクロールがあります。

「同じゲームと認識できる」かの最終判断はユーザー目視待ちです。完全一致や承認済みとは扱いません。

## 再現

Node 22、npm ci、npm run devを使用。PlaywrightとChromeが利用できる環境で次を実行します。必要ならPLAYWRIGHT_MODULEにPlaywrightのindex.mjsの絶対パスを指定してください。QA_OUTPUTは撮影先、QA_ORIGINは対象オリジンです。

```sh
node scripts/qa-shindan-capture-all.mjs preview
node scripts/qa-shindan-e2e.mjs
```

PreviewはPR専用Cloudflare Worker。本番用bindingを持たず、noindex、GET/HEADのみ、API・内部・会員ルートを遮断しています。masterへのpush・マージ・本番公開はしていません。
