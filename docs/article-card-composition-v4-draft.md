# NARU｜アイキャッチ構図の多様化（提案・未承認）

目的: 記事の内容によって「出来事」を描き、顎に手を当ててPCを見る人物を量産しない。

- **禁止する汎用ポーズ**: 顎に手を当てる、腕組みで悩む、ノートPC画面をただ見つめる。理由なく人物をデスクに座らせない。
- **人物を必須にしない**: 契約書の手渡し・出口を通る後ろ姿・書類の拡大・現場の俯瞰・テーマとなる物体のみ、などから記事固有の象徴を選ぶ。
- **構図は記事別に変える**: 動作／オブジェクトのクローズアップ／タイポグラフィ／対比／俯瞰など。いつも左文字・右人物に固定しない。
- **直近5枚と比較する**: 視点、人物の姿勢、タイトルの位置、余白、主役オブジェクトが重複する場合は描き直す。
- **NARUブランドを保持**: 既存の背景 #FBF8F3、文字・枠 #1F6F66、差し色 #B5691B、手描き編集イラストの質感を維持する。
- **情報設計**: タイトル一つ・人物や象徴物は主役一つ。実在ロゴ・社名、透かし、誤った数値、長いサブタイトルは禁止。
- **公開済み画像の差し替え禁止**: 本稿は次回制作の提案。承認前に既存記事の画像を上書きしない。
