「業務委託を辞めたいけれど、退職日の何日前に言えばいいのか分からない」。

正社員から業務委託へ切り替えた人ほど、会社員時代の「退職」と同じ感覚で考えやすいところです。

ただし、真正な業務委託は雇用契約ではありません。自分から仕事を終えたいときは、最初に契約書の終了条件を確認し、発注者から契約を切られる場合のルールと混同しないことが重要です。

この記事では、正社員から業務委託へ切り替えた人や、IT・Web系の業務委託で働いている人向けに、途中で抜ける前に確認したい順番を整理します。

## 業務委託を「退職」と同じ手続きで考えない

会社員は会社と雇用契約を結びます。一方、真正な業務委託では、業務の完成や遂行を目的とした事業者間の契約として扱われます。

そのため「退職届を出せば終わる」「2週間前に言えば必ず辞められる」といった会社員向けの説明を、そのまま業務委託へ当てはめるのは危険です。

まず確認するのは、契約書に書かれた次の項目です。

| 確認するもの | 見るポイント |
| --- | --- |
| 契約期間 | いつからいつまでか、自動更新か |
| 中途解除 | 途中で終了できる条件があるか |
| 通知期限 | 何日前までに伝えると定めているか |
| 通知方法 | 書面、メールなどの指定があるか |
| 成果物 | 終了時点で何を納品する必要があるか |
| 報酬 | 途中終了までの報酬計算はどうなるか |
| 経費 | 立替費用の精算方法はあるか |
| 引き継ぎ | データ返却やアカウント削除の定めがあるか |

契約書に「解約は1か月前までに通知」とあるなら、まずその条項を起点にします。

一方で、契約の種類や条項によって法的な扱いは変わるため、契約書に書かれていることだけで「必ず有効」「必ず無効」と決めることも避けます。

## 「30日前に言えばいい」は誰に向いたルールか

業務委託の契約終了を調べると「30日前」という数字がよく出てきます。

ここで混同しやすいのが、フリーランス法の中途解除等の事前予告です。

公正取引委員会と厚生労働省の案内では、一定の継続的業務委託について、発注事業者が契約を解除したり更新しなかったりする場合、原則として少なくとも30日前までに予告する義務があります。

これは「フリーランス本人が自分から辞める場合は30日前に言えば必ず終了できる」というルールではありません。

（出典：[公正取引委員会「フリーランス法特設サイト」](https://www.jftc.go.jp/freelancelaw_2025/)、[厚生労働省「フリーランス法に基づく就業環境整備のポイント」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/bunya/freelance_00006.html)）

発注者から突然契約終了を告げられた場合は、[正社員から業務委託に切り替えた後、契約終了されたら？](/articles/outsourcing-contract-termination-worker-status)で別に整理しています。

## 途中で抜ける前に確認する5つのこと

自分から契約を終えたいときは、感情的に「明日から行きません」と伝える前に、少なくとも5点を並べて確認します。

### 1. 契約終了日と通知期限

契約満了まで待つのか、中途解除を申し出るのかで話が変わります。

自動更新条項がある場合は「更新しない意思をいつまでに伝えるか」も確認します。

### 2. 進行中の仕事と成果物

制作中のWebサイト、コード、記事、広告運用、顧客対応などが残っているなら、どこまでが自分の納品範囲かを整理します。

途中経過のデータを勝手に削除したり、逆に会社のデータを私物端末へ持ち出したりしないことも重要です。

### 3. 引き継ぎの範囲

引き継ぎは「無限に付き合う」ことでも「何もしなくてよい」ことでもありません。

契約上の義務と、合理的に必要な作業を分けます。アカウント、担当案件、未処理タスク、顧客との連絡状況などを一覧にすると話が早くなります。

### 4. 未払い報酬と経費

最終月の報酬、出来高分、立替経費、請求書の締め日を確認します。

フリーランス法の対象となる取引では、発注時の取引条件や報酬額、支払期日などを書面や電磁的方法で明示する義務があります。

（出典：[公正取引委員会「フリーランス法特設サイト」](https://www.jftc.go.jp/freelancelaw_2025/)）

報酬条件そのものを見直したい場合は、[仕事は同じなのに正社員から業務委託へ。報酬が増えれば問題ない？](/articles/employee-contractor-pay-comparison)も確認してください。

### 5. 違約金・損害賠償の記載

契約書に違約金や損害賠償の条項がある場合でも、その一文だけを見て自己判断で支払ったり、逆に無視したりしない方が安全です。

契約の種類、終了理由、実際に生じた損害、条項の内容などで評価が変わります。金額が大きい場合や争いになっている場合は、法律相談につなげます。

## 伝えるときは「辞めます」だけで終わらせない

実務では、口頭だけでなく記録が残る方法で次の順番を整理すると、認識違いを減らせます。

1. 契約を終了したい意向
2. 希望する終了日
3. 契約書のどの条項を確認したか
4. 残っている業務と成果物
5. 引き継ぎ方法
6. 最終報酬と経費精算の確認

相手と協議した内容も、後から確認できるようにメールなどで残します。

「円満に辞めるため」だけではなく、いつ何を合意したのかを自分でも確認できる状態にするためです。

## 「業務委託なのに辞めさせてもらえない」なら働き方も見る

契約書に業務委託と書かれていても、実際の働き方によっては労働基準法上の労働者に該当する可能性があります。

厚生労働省は、契約の名称ではなく実態から総合的に判断すると説明しています。主な判断要素には、仕事を断る自由、業務遂行上の具体的な指揮監督、勤務場所や勤務時間の拘束、報酬の労務対償性などがあります。

（出典：[厚生労働省「労働者とは」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/keiyaku/index02.html)）

たとえば、

- 毎日9時から18時まで会社指定で勤務する
- 上司が作業手順まで具体的に指示する
- 仕事を断る選択肢がほぼない
- 社員と同様の勤怠報告を求められる

といった事情があるからといって、1項目だけで直ちに労働者と決まるわけではありません。

ただ、「事業者間の契約だから何も言えない」と諦める必要もありません。

働き方が気になる場合は、[偽装請負と偽装フリーランスは同じ？](/articles/disguised-contracting-freelance-difference)もあわせて確認してください。

## 相談先は論点で分ける

契約上のトラブルと、労働者性の問題では相談先が異なります。

契約解除、違約金、未払い報酬など契約上の争いは、フリーランス・トラブル110番などの法律相談が選択肢になります。

一方、自分の働き方が実態として労働者ではないかと疑う場合、厚生労働省は全国の労働基準監督署に「労働者性に疑義がある方の労働基準法等違反相談窓口」を設けています。

（出典：[厚生労働省「労働者性に疑義がある方の相談窓口」](https://www.mhlw.go.jp/stf/newpage_44487.html)）

## まとめ：先に契約終了の条件を可視化する

業務委託を辞めたいときに最初にすることは、退職届を書くことではありません。

契約期間、解除条項、通知期限、成果物、引き継ぎ、報酬を一度並べます。

そして、

「自分から契約を終えたい問題」

と、

「そもそも実態が労働者ではないかという問題」

を分けます。

正社員から業務委託への切り替え自体に疑問がある場合は、[正社員から業務委託への切り替えはクビ？断れる？](/articles/business-outsourcing-conversion-risk)から確認すると整理しやすくなります。
