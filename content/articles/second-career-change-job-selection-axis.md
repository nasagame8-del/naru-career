2回目の転職で、僕が特に重視したのは、**会社の安定性、契約と働き方、将来のキャリア**でした。

初めて飲食業界からIT/Web業界へ転職したときは、営業力が身につくことや、成長できそうな環境に強くひかれていました。その気持ち自体がなくなったわけではありません。ただ、今回は「そこで安心して働き続けられるか」も、同じくらい大切になったんです。

背景には、前の職場での契約や支払いをめぐる不安がありました。次の仕事では何ができるかだけでなく、どのような条件で働き、その先に何を目指すのかまで納得して決めたい。そんな気持ちで、会社選びをやり直しました。

この記事では、僕が実際に考えたことと、面談や提示資料を通じて確かめたことを振り返ります。特に、ChatGPTへ何を伝え、どんなやり取りで考えを整理し、回答をどう確かめたかまで書きます。

本文中の質問例は、同じように試したい人のために作ったものです。僕がその文面をそのまま入力したものではありません。

## 初回の転職では、成長できそうな環境にひかれた

飲食業界を離れるとき、僕には「営業として力をつけたい」という思いがありました。評価の基準が分かり、その評価が自分に返ってくることも重視していました。

IT/Web企業を選んだのは、無形のサービスを扱う法人営業を経験できること、裁量を持って働けること、経営者の営業力や考え方に魅力を感じたからです。

実際、SEO・AIO領域の法人営業では、自分に合う話し方を探したり、顧客の状況に合わせて提案を考えたりする経験ができました。そこで学んだことまで、なかったことにしたいわけではありません。

一方、今振り返ると、会社に入ってからの自分を長い目で考える準備は足りませんでした。目の前の営業力をどう伸ばすかは考えても、数年後にどんな仕事をしたいのか、その会社でどう働き続けるのかまでは、十分に言葉にできていなかったと思います。

初回の転職で感じた反省は、[第二新卒の転職で経験した失敗と会社選びの注意点](/articles/second-new-grad-job-change-traps)にもまとめています。今回は、その経験を受けて何を変えたかが中心です。

## ChatGPTには、理想の条件より先に「前の仕事で困ったこと」を話した

会社選びの軸を考えるとき、僕はChatGPTに一度で正解を出してもらったわけではありません。これまでの入社理由と退職理由、働いていて感じたこと、今回大切にしたいことを話し、問い返してもらいました。

初回の転職で求めたのは営業力や成長環境、評価への納得感。今回気になったのは会社の規模や安定性、契約と働き方でした。両方を話すと、「何を重視するか」だけでなく、「なぜ前回より大事になったのか」を考える材料になりました。

僕がやったことを分けると、次の流れです。

| 自分から伝えたこと | 壁打ちで整理したこと |
| --- | --- |
| 前回、その会社を選んだ理由 | 今も大切にしたい条件は何か |
| 実際に働いて困ったこと、不安に感じたこと | 次は繰り返したくないことは何か |
| 今回気になっている条件 | その条件に、どんな安心や働き方を求めているか |
| AIの提案と自分の感覚が違うところ | どこが違うのかを伝え、考え直した |

AIの説明がきれいにまとまっていても、自分の考えと違えば伝え直しました。この原稿を作るときも、最初は「顧客の課題を解決したい」という面が中心になりましたが、会社選びでは安定性や働き方も大きかったと補っています。

**もっともらしい転職理由を完成させるより、自分が本当に気にしていることを見落とさないための相手として使った**、という感覚に近いです。

### 試すなら、理由を聞き返してもらう

以下は読者向けに作った質問例です。会社名や個人名を書かなくても、状況と自分の気持ちから始められます。

```text
転職先を選ぶ基準を整理したいです。

前の会社を選んだ理由：
実際に働いて困ったこと：
次の会社で重視したいこと：
まだ迷っていること：

まず、この内容を整理してください。
そのうえで、なぜその条件が大事なのかを
私の経験から説明できるよう、一つずつ質問してください。
私が話していない経験や理由は補わないでください。
```

僕の場合、会社の規模への関心を掘り下げると、知名度だけでなく「安心して仕事を続けたい」という希望がありました。そこから、次に確かめる条件を具体的に考えるようになりました。

## 会社の規模に求めたのは、安心して仕事に向き合える基盤だった

今回、会社の規模を気にするようになったのは、安定性を重視したかったからです。

前の職場では、給与・報酬の支払いをめぐる問題を経験しました。生活に関わることが不安定になると、仕事の内容や成長の話だけでは済まなくなります。

それまでの僕は、「自分が頑張って成長できるか」という方向に考えが寄っていました。今回は、その頑張りを続けられる土台も大事にしたいと思うようになりました。

ただ、僕が会社の規模に安心感を求めたことと、大きな会社ならどこでも安心できることは別です。規模だけで条件を分かったつもりにならず、自分に提示された働き方も確認する必要がある、と考えました。

![会社の規模、契約と働き方、続けたい仕事を別々に確認する図](/images/articles/second-career-change-job-selection-axis-01.webp)

### 契約の名前と、実際の働き方を曖昧にしたくなかった

もう一つ気になったのが、契約と働き方の関係です。いわゆる「偽装フリーランス」のような状態になっていないか、という不安もありました。

ここで書きたいのは、前の職場の契約をこの記事で法的に判定することではありません。僕自身が契約に不安を感じた経験から、次は「どういう立場で、どんな条件で働くのか」を曖昧にしたくなかった、ということです。

厚生労働省の[「労働者とは」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/keiyaku/index02.html)でも、労働者に当たるかは契約の名称だけでなく、実際の働き方などから個別に判断されると説明されています。

制度や確認項目の詳しい話は、[偽装フリーランスと労働者性の確認点](/articles/fake-freelancer-worker-status-guide)に分けています。今回の僕にとっては、働く条件への不安を抱えたまま、会社への期待だけで決めないことが大切でした。

## 年収だけでなく、月々の生活と働き方まで確認した

労働条件も、今回はちゃんと見ようと決めていました。以前、求人票で見た給与と入社後に示された金額にずれがあったことも、その理由です。

提示年収を聞いて終わりにするのではなく、月々の収入と、実際の生活を考えるところまで進めました。ChatGPTとの壁打ちでは、家賃や生活費を踏まえ、手取りの目安も試算しています。

ただ、その試算はあくまで仮定を置いた計算でした。会社から示された給与や賞与の条件と、AIが計算した見込みは同じではありません。

特に印象に残っているのは賞与です。最初の壁打ちでは、支給される時期や金額について仮定を置いていました。その後、入社に関する資料を読むことで、自分の入社時期に応じた初回賞与の扱いを整理し直しました。

**年収の総額が分かっても、いつ、どのように受け取るかまでは分からない。** 今回はその違いを、生活の見通しと結びつけて考えました。

![年収の総額に加えて月給、賞与、勤務時間と休日、副業条件を確認する図](/images/articles/second-career-change-job-selection-axis-02.webp)

### AIに整理してもらう内容と、会社へ確認する内容を分けた

僕は提示された条件や入社資料の内容をもとに、ChatGPTと給与・賞与・生活費について相談しました。自分だけでは混ざりやすかった年収、月給、賞与の時期、手取りの見込みを分けることに使っています。

ここで大事だったのは、AIが数字を出しても、その前提まで確定したわけではないことでした。賞与の扱いは、最初の仮定のままにせず、会社の資料で確認し直しています。

| 段階 | 実際に進めたこと |
| --- | --- |
| 条件を整理する | 提示内容と、分からない点をChatGPTに伝えて相談した |
| 生活を考える | 家賃や生活費を踏まえ、月々の収入の見通しを試算した |
| 前提を確かめる | 給与・賞与に関する会社の資料や説明と照合した |
| 働き方を確かめる | 担当者とのやり取りで勤務時間・休日・副業などを確認した |

読者が使うなら、計算を頼む前に「分かっている条件」と「まだ分からない条件」を分けてもらうと、確認する点が見えやすくなると思います。以下も記事用の質問例です。

```text
転職先から示された条件を整理したいです。
会社名・個人名などを除き、必要な項目だけ書きます。

提示年収：
月給と内訳：
賞与について書かれている内容：
入社予定時期：
勤務時間・休日：
副業についての説明：
毎月の生活費：

この情報だけで分かること、不明なこと、
仮定を置かないと計算できないことを分けてください。
不明な会社の制度や支給時期は推測せず、
担当者へ確認する質問を挙げてください。
```

この形式なら、AIの回答をそのまま承諾の根拠にするのではなく、会社への質問や、資料で探す項目を整理するために使えます。手取りを試算する場合も、税金や社会保険料などの前提によって結果が変わるので、確定した給与額とは区別して扱いたいところです。

### 休日・勤務時間・在宅勤務・副業も、自分の生活に関わる条件だった

内定後のやり取りでは、休日、勤務時間、在宅勤務、通勤手当、副業の条件なども確認しました。

副業は、僕にとって特に身近な話でした。個人でこのNARUを運営しているからです。「副業ができる」と聞いたとしても、申請の要否や、競業などに関する条件まで知ったうえで考える必要がありました。

今回の確認を振り返ると、見ていたのは次のようなことです。

| 気になったこと | 僕が整理した内容 |
| --- | --- |
| 月々の生活を続けられるか | 月給と賞与を分け、生活費を踏まえて考えた |
| 初回の賞与はどうなるか | 仮定の試算を、入社時期に応じた資料の説明と照合した |
| 日々の働き方はどうなるか | 勤務時間、休日、在宅勤務などの説明を確認した |
| 個人の活動を続けられるか | 副業の申請や制限を確認し、許可済みとは考えなかった |

これは僕の確認内容を振り返った表です。同じ制度名でも会社や個人の条件によって扱いは異なるので、具体的な勤務条件を他の人にそのまま当てはめることはできません。

書面での確認項目や質問の仕方が必要な場合は、[内定承諾前の労働条件・仕事内容の確認手順](/articles/second-new-grad-it-offer-acceptance-checks)にまとめています。

## キャリアビジョンは、入社後の仕事から考えた

今回、条件と同じくらい時間をかけたのが、将来のキャリアでした。

最初から、きれいな答えがあったわけではありません。ChatGPTを相手に「なぜその仕事なのか」「その先に何をしたいのか」と壁打ちしながら、自分の経験と希望を整理しました。

僕が応募したのは、インサイドセールス、略してISの仕事です。まだ関係のない顧客と接点をつくり、商談や課題解決の入口につなげることに、これまでの新規開拓営業でやりがいを感じていました。

そのうえで、まずISとして継続して成果を出せるようになる。将来はフィールドセールス、略してFSにも挑戦し、顧客への提案や意思決定の支援まで対応できる範囲を広げたい。さらに、自分だけでなくチーム全体の成果にも貢献したいと考えました。

![まずISで成果を積み、その先にFSへの挑戦とチームへの貢献を考える図](/images/articles/second-career-change-job-selection-axis-03.webp)

### やりたいことと、会社が約束していることは別だった

このキャリアビジョンは、僕自身の希望です。「何年働けば必ずFSに異動できる」「将来は必ず管理職になれる」と約束された、という話ではありません。

会社から聞いた将来の選択肢と、自分が目指したい方向を重ねながら考えました。まず任されるISの仕事で何を身につけたいのかが、自分の中で分かったことに意味がありました。

前回は「営業力がつきそう」という期待が先にありました。今回は、どんな経験を積み、その先で何をしたいのかを、自分の言葉で説明できるようにしたかったんです。

### キャリアの相談では「なぜISなのか」から問い返してもらった

キャリアについても、ChatGPTに将来像を一方的に作ってもらう使い方ではありませんでした。「なぜFSではなくISなのか」と聞かれたとき、僕は、まだ接点のない顧客と関係をつくる仕事にやりがいを感じる、と説明しました。

ただ、「お客様に満足してもらえるから」だけでは、FSを選ぶ理由とも重なります。そこで、新規開拓営業の経験を振り返りながら、最初の接点を生み出すことに、なぜ面白さを感じるのかを掘り下げました。

将来FSに挑戦したい気持ちも伝えました。そのうえで、今のISの仕事を選ぶ理由と、その先の希望がつながるように考えています。

この壁打ちから整理したのは、次の3点です。

- 今の仕事で、どんな場面にやりがいを感じていたか
- 次の仕事で、何を身につけて成果につなげたいか
- その経験を、その先にどう広げたいか

以下は、その考え方を試すための質問例です。

```text
希望職種について、キャリアの考えを深掘りしたいです。

これまで経験した仕事：
やりがいを感じた具体的な場面：
次に希望している職種：
その先に挑戦したい仕事：

「なぜ今その職種なのか」
「そこで何を身につけたいのか」を一つずつ質問してください。
抽象的な答えには、実際の経験を聞き返してください。
私自身の希望と、会社に確認が必要なことは分けてください。
```

こうして言葉にした希望をもとに、会社が示す将来の選択肢も確かめました。AIと考えを整理することと、会社に制度や仕事の可能性を聞くことは、役割が違いました。

## 内定が出てからも、会社を選ぶ時間を取った

内定をもらえたのは、もちろんうれしかったです。ただ、それだけで判断を終えたくはありませんでした。

オファー面談、現場社員との面談、人事とのやり取り、職場見学を通じて、仕事内容や条件、働く環境を確認しました。長期的なキャリアを描けることと、生活に関わる条件に納得できることを、自分の判断の中に置きたかったからです。

だからといって、入社後のすべてが分かったわけではありません。今の時点で「この会社選びは成功だった」と言い切ることもできません。

それでも、前回より考えて決められたことはあります。

| 初回の転職で強く見ていたこと | 今回、重ねて考えたこと |
| --- | --- |
| 営業力を身につけられそうか | 安心して仕事を続けられる基盤があるか |
| 裁量や成長の機会がありそうか | 契約や日々の働き方に納得できるか |
| 求人や面接で魅力を感じるか | 提示資料と説明を踏まえて生活を考えられるか |
| 新しい仕事に挑戦できるか | その仕事から、どんなキャリアを目指したいか |

会社選びの軸が変わったというより、仕事を経験して、見たいところが具体的になったのかもしれません。

成長したい気持ちは今もあります。そのためにも、安心して働ける条件と、自分が向かいたい方向を、会社への期待と一緒に考えるようになりました。それが、2回目の転職で僕が変えたことです。
