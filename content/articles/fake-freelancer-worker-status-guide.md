「契約書では業務委託なのに、社員と同じ時間に出社し、上司から毎日の仕事を指示される」。そんな働き方に違和感があるなら、**偽装フリーランスの問題**を一度確認してみる価値があります。

結論から言うと、業務委託契約を結んでいても、実態によっては労働基準法上の「労働者」に当たる可能性があります。**判断の中心は、誰の指揮監督下で働き、何の対価として報酬を受け取っているか**です。

ただし、朝会への参加や固定報酬など、気になる項目が一つあるだけで違法とは決まりません。この記事では、厚生労働省が公開している自己診断チェックリストを手掛かりに、IT・Webの働き方を整理し、相談に進むまでの手順を示します。以下の場面例は理解のための仮定であり、実在企業の違法性を認定するものではありません。

## 偽装フリーランスとは？契約書より「働き方の実態」を見る

![業務委託契約と実際の働き方を分けて考える図](/images/articles/fake-freelancer-worker-status-guide-01.webp)

「偽装フリーランス」は、一般に**契約上はフリーランスや業務委託でも、働き方の実態が労働者に当たる可能性がある状態**を指します。

労働基準法第9条の労働者性について、厚生労働省は主に「他人の指揮監督下で労働しているか」「報酬がその労働の対価か」という使用従属性を基礎に、仕事の諾否、指示、拘束性などを個別に総合判断すると説明しています。

| 契約・実態 | まず見ること |
| --- | --- |
| 契約は業務委託、仕事の進め方も自分で決める | 独立した事業者としての実態があるか |
| 契約は業務委託、勤務や仕事の進め方は会社が決める | 労働基準法上の労働者性がないか |
| 正社員から業務委託へ変更を求められた | 雇用を終了する手続と、変更後の労働者性を分ける |

「偽装請負」という言葉とも混同しがちです。偽装請負は企業間の請負・派遣関係が論点になりやすく、個人の労働者性とは必ずしも同じ問題ではありません。違いは[偽装請負と偽装フリーランスの比較](/articles/disguised-contracting-freelance-difference)で整理しています。

出典：[厚生労働省「労働基準法における『労働者』とは」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/keiyaku/index02.html)

## 厚生労働省の「8項目」は自己整理の道具。違法判定の点数表ではない

厚生労働省の「働き方の自己診断チェックリスト（フリーランスの方向け）」には、次の8つの確認項目があります。

![仕事の自由・指示・報酬の見方を整理する図](/images/articles/fake-freelancer-worker-status-guide-02.webp)

| 公式の確認項目 | 自分の働き方で確認する例 |
| --- | --- |
| 1. 仕事を断る自由 | 追加案件を断ると、契約違反だと言われるか |
| 2. 業務の指揮監督 | 毎日の作業量・順序・進め方を会社が細かく決めるか |
| 3. 時間・場所の拘束 | 始業・終業や出社場所を会社に決められ、管理されるか |
| 4. 代替性 | 別の担当者への再委託や代役を認められるか |
| 5. 報酬の性格 | 成果・出来高より、働いた日数や時間に応じて支払われるか |
| 6. 資機材の負担 | 仕事の道具や設備を主に誰が用意しているか |
| 7. 報酬の水準 | 同種の仕事をする正社員の報酬や、自分の経費負担と比べてどうか |
| 8. 専属性 | 他社の仕事が実質的に制限され、一社に長く従事しているか |

ここで**「8個中4個なら偽装フリーランス」といった基準を作ってはいけません**。厚生労働省のチェックリストは相談や事実整理の手掛かりで、公式の合否判定ではありません。また項目ごとの意味や重みも同じとは限らず、関係する契約内容や仕事の性質を合わせて考える必要があります。

たとえば発注先のシステムを扱うために会議時刻を合わせることと、毎日の始業時刻から休暇の取得方法まで社員同様に管理されることは、同列に判断できません。**どんな指示だったのか、何を断れなかったのか**を具体的に残す方が役に立ちます。

出典：[厚生労働省「働き方の自己診断チェックリスト」掲載ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/keiyaku/index02.html)、[フリーランスとして安心して働ける環境を整備するためのガイドライン](https://www.check-roudou.mhlw.go.jp/study/roudousya_freelance.html)

## IT・Webの現場で迷いやすい3つの場面

### ケース1｜「毎朝9時に出社して日報も出す」

仮にWeb制作の委託契約なのに、発注者が出社・退勤時刻を毎日決め、遅刻や欠勤の扱いまで細かく管理しているなら、拘束性を検討する材料になります。

一方、顧客の営業時間に合わせて週1回の打ち合わせ時間を決めるだけなら、事情は異なります。報告頻度という形式より、**働く時間を誰が決め、変更できるか**が重要です。

朝会、Slack、勤怠記録の扱いは[業務委託なのに9時出社・勤怠管理を求められるケース](/articles/contractor-attendance-control-worker-status)で詳しく扱っています。

### ケース2｜「仕事を断れず、上司から作業の順番を指示される」

仮にWebマーケティングの業務委託で、契約範囲を超える仕事も断れず、毎朝社員のように業務を割り振られるなら、諾否の自由と指揮監督の有無が重要です。

発注者が「広告文をこの仕様にしてほしい」と成果物の条件を伝えることと、「今日はこの順番で電話をかけ、何時に休憩を取ること」と働く過程を管理することは同じではありません。

ただし、仕事の性質上どうしても作業順序を調整する必要がある場合もあるため、指示があったという一事だけで結論は決められません。

### ケース3｜「固定月額で、他社の仕事もできない」

月額固定報酬や専属契約だけで直ちに労働者になるわけではありません。出来高との関係、拘束性、事業者としての裁量や経費負担を一緒に確認します。

例えば、案件を自分で選べず、会社の勤務表で拘束され、報酬も一定の労働時間に対して支払われているなら、複数の事情をまとめて整理する必要があります。他社との契約を制限する条項は[業務委託の兼業・競業禁止の確認点](/articles/contractor-exclusivity-noncompete-checks)で別に解説しています。

**3つのケースはいずれも仮定です。** 実際の適法・違法は契約書と働き方などから判断されます。

出典：[厚生労働省「労働者性」の判断基準](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/keiyaku/index02.html)

## 「フリーランス法があるから大丈夫」は別の話

2024年11月に施行されたフリーランス・事業者間取引適正化等法は、一定の業務委託取引について取引条件の明示や報酬支払い等のルールを設ける法律です。

しかし、**事業者としての取引の保護と、実態が労働者であるかどうかは別の問題**です。公正取引委員会のQ&Aは、発注者との関係で受注者が労働基準法等の労働者に当たる場合、同関係ではフリーランス法の「特定受託事業者」には当たらず、労働関係法令が適用されると説明しています。

なお、労働組合法上の労働者性は労働基準法とは判断の枠組みが異なり、事業者としての取引保護と組合活動上の保護が両立する場合もあります。法令ごとの扱いを一つの「フリーランスか否か」だけで決めないことが大切です。

出典：[公正取引委員会「フリーランス法Q&A」Q5](https://www.jftc.go.jp/fllaw_limited/fllaw_qa.html)、[厚生労働省「フリーランスとして業務を行う方等へ」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/koyoukintou/zaitaku/index_00002.html)

## 偽装フリーランスかもしれないと思ったら、証拠を3種類に分けて残す

![記録・窓口・相談の3ステップを示す図](/images/articles/fake-freelancer-worker-status-guide-03.webp)

疑問があるときにすべきことは、「違法だ」と会社へ断定して伝えることではありません。まずは、何が起きていたかを後から確認できるようにします。

### 1. 契約の記録

契約書、条件通知、業務範囲、報酬の決め方、契約更新や変更時のメールを時系列に整理します。契約書が手元にない場合は[業務委託契約書がないときの確認事項](/articles/contractor-no-written-contract)も参考にしてください。

### 2. 実際の指示・拘束の記録

出社の指定、勤務表、朝会への参加指示、業務を断った際の返答、チャット上の作業指示、休暇の許可を求めた経緯などを、**日付・誰から・何を求められたか**の形で整理します。

スクリーンショットなどを使う場合も、顧客情報、個人情報、機密データを無断で持ち出すことは避けてください。自分が適法に保管・提出できる資料の範囲に留め、扱いに迷ったものは相談窓口で確認すると安全です。

### 3. 報酬と働いた時間の記録

請求書、報酬明細、入金履歴、稼働記録、経費負担を整理します。金額が固定か変動かだけでなく、何の仕事・何時間・どの成果に対する支払いなのかを確認できるようにしておくと、相談の際に状況を説明しやすくなります。

未払いが発生している場合は[業務委託の報酬未払いにどう対応するか](/articles/contractor-unpaid-fee-consultation)へ進んでください。

## 相談先は「労働者かもしれない」か「取引条件のトラブル」かで選ぶ

| 困っていること | 最初に確認する相談先 |
| --- | --- |
| 契約は業務委託だが、実態は労働者かもしれず労基法等の違反が疑われる | 労働基準監督署の「労働者性に疑義がある方の労働基準法等違反相談窓口」 |
| 真の業務委託としての契約・報酬・解除のトラブル | 厚労省委託事業「フリーランス・トラブル110番」 |
| フリーランス法の取引条件明示や支払義務などの違反が疑われる | 公正取引委員会・中小企業庁等の制度案内・申出窓口 |

厚生労働省は、2024年11月1日から全国の労働基準監督署に労働者性の疑いに関する相談窓口を設けています。案内されている受付時間は**平日8時30分〜17時15分**です。相談しただけで自動的に労働者と認定されるわけではありませんが、具体的な事情を話して次の手続きを確認できます。

- [厚生労働省「労働者性に疑義がある方の相談窓口」](https://www.mhlw.go.jp/stf/newpage_44487.html)
- [フリーランス・トラブル110番（厚労省委託事業）](https://freelance110.mhlw.go.jp/)
- [公正取引委員会「フリーランス法Q&A」](https://www.jftc.go.jp/fllaw_limited/fllaw_qa.html)

**相談する前に退職届へ署名したり、証拠を消したりする必要はありません。** ただし、退職や契約終了の期限が迫る場合は、個別の契約・法令によって対応が異なるため、早めに窓口や専門家へ確認してください。

すでに契約終了を告げられた場合は[業務委託を突然切られた場合の30日前予告・対処法](/articles/outsourcing-contract-termination-worker-status)、まだ正社員で委託への切り替えを打診されている場合は[正社員から業務委託への切り替えを断った場合の確認点](/articles/business-outsourcing-conversion-risk)が先に役立ちます。

## まとめ：契約名だけで諦めず、「誰が働き方を決めているか」を確かめる

偽装フリーランスを疑ったときに大切なのは、契約書の表題でも、チェック項目の数でもありません。**会社からの具体的な指示、仕事を断る自由、時間・場所の拘束、報酬の性質**を、実際の記録とともに整理することです。

業務委託そのものは合法な契約形態です。一方、名目は事業者でも働く実態が労働者なら、法令上の保護を検討すべき場合があります。自分だけで違法性を決めつけず、公的な判断基準と相談窓口を使って確認する。その順序が、感情的な対立を避けながら状況を前に進めるための出発点になります。

（本記事は2026年10月31日時点で確認した公的資料に基づく一般的な情報整理であり、個別案件の法的判断や法律相談の代替ではありません。）
