納品は終わった。請求書も送った。それでも、約束した支払日を過ぎた口座に入金がない。

「催促したら次の仕事がなくなるのでは」「自分の請求に不備があったのか」。初めて業務委託で働くと、支払いを確かめるだけでもためらうことがあります。

まずは、約束した支払日と入金履歴を照合し、どの仕事の報酬が残っているのかを特定してください。契約・納品・請求・相手の返答を残し、支払い状況を文書で確認するところから始めます。返答がない場合や、支払日が繰り返し延びる場合は、一人で連絡を続けるより相談窓口を使う方がよい場面もあります。

**最初に確認するのは「どの仕事の報酬が、いくら、いつ支払われる約束だったか」です。** 請求書や契約の記録を並べ、支払期日を過ぎているなら相手に支払状況と具体的な予定日を文書で尋ねます。

| 今の状況 | まず取る行動 |
| --- | --- |
| 支払日を過ぎたが、会社から説明がない | 契約・請求・入金明細を照合し、予定日をメールで確認 |
| 「請求書が遅れた」「処理中」と説明された | 当初の合意期日と、後から示された予定日を別々に残す |
| 連絡がない・延期が続く | 証拠をまとめ、フリーランス・トラブル110番などへ相談 |
| 業務委託だが出退勤や業務の進め方を会社に管理されている | 労働者性を整理し、必要に応じ労基署の専用窓口へ確認 |

この記事は、支払日を過ぎても報酬が入らないときの初動に絞ります。仕事を始める前の条件が分からない場合は、[業務委託の契約書がないときの確認方法](/articles/contractor-no-written-contract)を先に確認してください。

契約終了を告げられたうえで報酬も未払いになっている場合は、支払いの問題と契約終了の問題を分けて整理してください。[業務委託の契約を突然切られたときの確認点](/articles/outsourcing-contract-termination-worker-status)では、終了の予告や労働者性の論点を扱っています。

## 未払いの対象を「どの仕事・いくら・いつ」で特定する

入金がないと分かったら、まず口座の明細と、発注時に示された条件を並べます。「今月分がまだ」だけでは、複数案件や追加作業があると認識がずれやすくなります。

| 確認する項目 | 見る資料 |
| --- | --- |
| 誰に請求する仕事か | 契約書、発注書、発注メール |
| 何の仕事の報酬か | 案件名、対象期間、追加発注の記録 |
| 報酬額と支払期日 | 条件の明示、請求書、支払いの案内 |
| 全額未払いか、一部だけ残っているか | 入金履歴、支払明細 |

担当者の名前だけでなく、契約上の相手方も確認します。IT/Webの仕事で、作業先と契約先が異なる場合は、誰から発注を受け、誰が支払う条件なのかを分けて整理してください。

![報酬未払いの対象を案件、報酬額、支払日で特定する図解](/images/articles/contractor-unpaid-fee-consultation-01.webp)

一部入金があるなら、その日付と金額も残します。入金差額が振込手数料などの控除によるものなのか、別案件が未払いなのかは、相手の支払明細と照合して確かめます。差額だけで原因を決めつけず、手数料控除が気になる場合は[振込手数料を報酬から差し引かれたときの確認点](/articles/contractor-bank-transfer-fee-deduction)も参照してください。

## 支払期日と「60日以内」のルールを分けて考える

フリーランス法の報酬支払義務が適用される取引では、発注者は給付を受領した日から起算して60日以内のできる限り短い期間内に支払期日を定め、その日までに支払う必要があります。「60日までは、約束した日を過ぎても待つ」という意味ではありません。

この義務は、同法上のフリーランスへの委託について、発注者が「特定業務委託事業者」に当たる場合に適用されます。従業員を使用する個人、または役員が二人以上いるか従業員を使用する法人などが対象です。受注側の要件もあるため、業務委託という名称だけで適用を断定しません。

また、必要事項を明示した再委託には、元委託支払期日を基準とする例外があります。開発の再委託だから自動的に例外になるわけではありません。納品、役務の提供、検査、請求書の提出を混同せず、今回の期日がどう定められたかを確認します。

出典：[公正取引委員会「フリーランス法のパンフレット」支払期日・再委託の例外](https://www.jftc.go.jp/file/flpamph.pdf)

### 「請求書が遅れた」「社内処理が遅れた」と言われたら

対象取引では、請求書の提出が遅れたことだけを理由に、定めた支払期日を過ぎてよいわけではありません。公正取引委員会の2026年6月18日の勧告には、請求書の提出や社内処理の遅れを理由に、期日までに報酬を支払わなかった事例が記載されています。

出典：[公正取引委員会「株式会社エス・ピー・シーに対する勧告について」（2026年6月18日）](https://www.jftc.go.jp/houdou/pressrelease/2026/jun/260618_spc.html)

請求書の送付先や形式に不備があれば、再送など必要な対応は行います。そのうえで、当初の支払期日、遅れている理由、具体的な支払予定日を確認してください。「処理中です」だけなら、いつの支払いを予定しているかまで尋ねます。

## 相談に使える記録を四つにまとめる

資料は大量に送るより、仕事を受けてから現在までの順番が分かる形にすると説明しやすくなります。次の四つを案件ごとにまとめる方法があります。

![未払いの相談に備えて契約、納品、請求、連絡の記録をまとめる図解](/images/articles/contractor-unpaid-fee-consultation-02.webp)

| 記録 | 残すもの |
| --- | --- |
| 契約・発注 | 報酬と支払日の分かる文書、追加作業の合意 |
| 納品・作業 | 提出日時、納品メール、受領の返答、作業報告 |
| 請求・入金 | 請求書、送信履歴、入金明細 |
| 相手との連絡 | 支払予定の回答、延期の説明、電話後の確認メール |

チャットは該当箇所だけでなく、相手・日付・前後の文脈も確認できる形で保存します。ファイル名を案件名と日付でそろえ、元のメールやデータも残してください。電話で説明を受けた場合は、「本日のお話では、支払予定日はこの日と伺いました」とメールで確認する方法があります。

IT/Web案件では、納品の証拠を集めるために、顧客データや他社のソースコードを私用の場所へ持ち出さないようにします。自分が正当に保管できる発注・送付・受領の記録を使い、共有してよい範囲が分からない資料は相談先へ扱いを確認してください。

## 最初の連絡は、支払い状況と予定日の確認に絞る

最初から相手の意図を断定する必要はありません。対象の案件、期日、現時点で入金が確認できないことを伝え、具体的な回答を求めます。次はNARUの編集例です。実際の情報に合わせて書き換えてください。

> 件名：納品済み案件の報酬支払いについて
>
> お世話になっております。先日納品した案件について、合意した支払期日を過ぎましたが、現時点で入金を確認できておりません。
>
> 対象案件、請求書、合意した報酬額と支払期日を添付いたします。支払い状況と、具体的な支払予定日をご回答いただけますでしょうか。請求書の再送などが必要な場合はお知らせください。

金額や日付を入れた完成文を見直し、送信履歴と返答を保存します。相手が別の日を示した場合も、当初の期日と新たな回答を分けて残してください。

返答がない、延期が繰り返される、納品後に連絡が途絶えた、といった場合は、催促の回数を増やすことだけで解決しようとしない方がよいでしょう。相談は、この文面を送った後でないとできないものではありません。不安が強いときは先に利用できます。

## 未払いの相談先は、個別の請求と法違反の確認で選ぶ

![報酬未払いの対応を記録整理、支払い確認、窓口相談の順に示す図解](/images/articles/contractor-unpaid-fee-consultation-03.webp)

フリーランス・トラブル110番は、厚生労働省委託事業として第二東京弁護士会が運営し、報酬の未払いや一方的な減額などの相談に対応しています。弁護士への相談は無料で、匿名での相談も可能と案内されています。

出典：[フリーランス・トラブル110番](https://freelance110.mhlw.go.jp/)

「この資料で請求をどう進めるか」「相手の説明にどう返すか」を相談したい場合は、案件の時系列と記録を用意します。回収や解決が保証されるわけではありませんが、次の対応を考える材料になります。

一方、フリーランス法違反と思われる行為については、公正取引委員会などの行政機関への申出の窓口があります。行政への申出と、自分の報酬を回収するための個別の対応は、目的を分けて相談してください。

出典：[公正取引委員会「フリーランス法」相談・申出の案内](https://www.jftc.go.jp/fllaw_limited.html)

「業務委託と言われたが、働き方は社員と変わらない」という疑問がある場合は、報酬未払いとは別に労働者性の検討も必要になり得ます。[偽装フリーランスの公式判断基準8項目と相談先](/articles/fake-freelancer-worker-status-guide)に沿って、勤務の指示や時間管理の記録を整理してください。正社員から変更された経緯がある場合は[正社員から業務委託への切り替えの確認点](/articles/business-outsourcing-conversion-risk)も参考になります。

厚生労働省は全国の労働基準監督署に、労働者性に疑義がある人の労働基準法等違反相談窓口を設けています。ただし、窓口に相談しただけで労働者と認定されるわけではありません。契約の名称ではなく、実際の働き方を整理したうえで相談することが大切です。

出典：[厚生労働省「労働者性に疑義がある方の相談窓口」](https://www.mhlw.go.jp/stf/newpage_44487.html)、[公正取引委員会「フリーランス法Q&A」Q5](https://www.jftc.go.jp/fllaw_limited/fllaw_qa.html)
