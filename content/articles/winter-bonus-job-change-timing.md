冬のボーナスを受け取ってから会社を辞めたいと思っても、「12月にもらって、その翌日に退職を伝えればよい」と日付だけで決めるのは早計です。==賞与の支給条件を確かめ、次の入社日と現職の引き継ぎを並べて考えることが先になります。==

この記事は、在職中の第二新卒が冬の賞与と転職の予定を整理するためのものです。特定の会社の減額や返還請求の有効性を判定するものではありません。

## 冬のボーナスは「働いた期間」だけでは決まらない

厚生労働省の[「賞与不払い」の裁判例解説](https://www.check-roudou.mhlw.go.jp/hanrei/chingin/syouyo.html)では、賞与の請求権について具体的な算定基準・方法などとの関係が示され、支給日や一定の基準日に在籍する人を対象とする取扱いも有効とされています。

そのため、査定期間に働いていた事実だけで支給を断定せず、自社の規程を確認する必要があります。一方、「退職する人にはどんな理由でも払わなくてよい」と読み替えることもできません。規程と個別事情の確認が欠かせない論点です。

![査定期間・在籍条件・支給日を分けて確認する図](/images/articles/winter-bonus-job-change-timing-01.webp)

| 調べるもの | 確認する内容 |
| --- | --- |
| 就業規則・賃金規程 | 賞与の対象者、在籍要件、算定方法、業績等による扱い |
| 査定の案内 | 評価対象の期間、支給額が決まる時点 |
| 支給通知・明細 | 実際の金額、支払予定日、説明されている内訳 |
| 雇用契約等 | 個別に定めた賞与条件の有無 |

規程の所在が分からなければ、社内の閲覧方法を確認しましょう。過去の支給実績や同僚の話は参考になっても、自分の条件を確定する資料の代わりにはなりません。

## 「受け取ってから伝える」を唯一の正解にしない

退職を申し出る時期を考えるときは、賞与だけでなく引き継ぎ、休暇、転職先の受入日も関係します。支給日まで待った結果、次の会社へ約束した入社日に間に合わなくなるなら、日程の相談が必要です。

| 状況 | 先に確認したいこと |
| --- | --- |
| 次の会社が決まっていない | 賞与条件と生活費を確認しつつ、応募準備を進める |
| 内定があり入社日は相談中 | 賞与・引き継ぎを踏まえて希望入社日を伝える |
| 入社日を合意済み | 現職の予定と両立するかを再点検し、難しければ早めに相談する |
| 退職の申出後に減額を告げられた | 規程と通知、説明の記録をそろえ、理由を確かめる |

ここでの表は進め方の提案であり、退職を伝えた時期による賞与額の変化を予測するものではありません。賞与の扱いが不明な段階で「この日なら損をしない」と結論づけないことが大切です。

退職の伝え方は[第二新卒の退職実体験](/articles/how-to-resign-experience)も参考になります。ただし、個人の体験を自分の会社の規程として使わないようにしてください。

## 賞与と転職先の条件を同じ表で比べる

![賞与・次の給与・無収入期間・引き継ぎを比較する図](/images/articles/winter-bonus-job-change-timing-02.webp)

賞与を受け取れるかだけに集中すると、入社を遅らせた分の給与や、生活費の見通しが抜けます。判断の前に次の項目を手元の数字で埋めてみましょう。未確定の賞与額は「見込み」と記載し、確定額に混ぜません。

| 比較項目 | 記入する内容 |
| --- | --- |
| 現職の賞与 | 確定額か見込み額か、支給条件は何か |
| 現職の最終給与 | 支払日と支給対象期間 |
| 転職先の初回給与 | 初回の支払日、締日との関係 |
| 入社までの生活費 | 家賃や固定費を含め、収入がない期間に必要な額 |
| 日程を動かす影響 | 応募先に相談できるか、引き継ぎが成立するか |

計算結果だけで転職先を決める必要はありません。ただ、手元資金が足りるかを把握しておけば、賞与額の不確実さに合わせて予定を調整しやすくなります。

次の職場の給与は、月給欄の金額だけで比較せず、[内定承諾前に確認する労働条件](/articles/second-new-grad-it-offer-acceptance-checks)まで読み合わせましょう。

## 減額・不支給の説明に納得できないときの確認手順

![規程を読む、理由を聞く、記録をそろえて相談する三段階](/images/articles/winter-bonus-job-change-timing-03.webp)

まず、どの規程を根拠に、いつ、どのように金額が決まったのかを確認します。口頭だけの説明なら、認識した内容をメール等で確認して残す方法があります。

質問文は、たとえば次の形です。

> 今回の賞与の算定について確認したく、ご連絡しました。支給対象と査定期間、今回の金額に適用された規程の箇所をご教示いただけますでしょうか。

回答や規程、支給通知、雇用条件の資料をまとめても解消しなければ、[厚生労働省の総合労働相談コーナー](https://www.mhlw.go.jp/general/seido/chihou/kaiketu/soudan.html)などへ相談できます。相談先には「ボーナスが減った」という結果に加え、説明を受けた日と理由を時系列で伝えると整理しやすくなります。

## 転職活動の開始を、賞与の支給日まで待つ必要はない

求人の確認や職務経歴書づくりと、退職の申出は別の工程です。在職中に準備を進めておけば、内定後に提示条件と賞与の予定を並べて検討できます。

まずは賞与規程の確認と、転職先へ希望する入社日の書き出しから。どちらも曖昧なまま退職日だけを決めるより、相談に必要な材料がそろいます。
