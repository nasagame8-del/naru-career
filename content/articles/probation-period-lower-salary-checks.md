求人票には本採用後の月給が大きく書かれ、試用期間中の金額は小さな注記にある。入社後の生活費を考えると、いつ、どの条件で給与が切り替わるのかが気になります。

確認したいのは、金額の差に加えて、切替日・判断基準・延長条件です。試用期間が終われば必ず求人票の金額になると受け取らず、提示書面で確定している条件をそろえてから判断しましょう。

## 試用期間と本採用後の給与を同じ項目で比べる

![試用期間と本採用後の基本給、手当、固定残業代を比較する図](/images/articles/probation-period-lower-salary-checks-01.webp)

「月給」の総額だけを並べると、手当や固定残業代の違いが見えません。試用期間中と本採用後で、同じ項目を比較してください。

| 項目 | 質問したいこと |
| --- | --- |
| 基本給 | それぞれの金額はいくらか |
| 手当 | どの手当が、いつから付くか |
| 固定残業代 | 金額・対象時間・超過分の扱いはどうなるか |
| 契約期間 | 試用期間と雇用契約の期間は同じなのか |

厚生労働省は、契約締結時に賃金などの労働条件を明示することを案内しています。求人票と契約時の書面は役割が異なるため、面接で聞いた説明も併せて照合することが必要です。

出典：[厚生労働省「採用時の労働条件明示」](https://www.mhlw.go.jp/bunya/roudoukijun/faq_kijyunhou_4.html)

承諾前に書面を受け取れていない場合は、[労働条件通知書が届かないときの確認](/articles/offer-letter-before-acceptance-not-provided)も参考になります。

## 給与の切替日と判断基準を曖昧にしない

![給与の切替日、判断基準、延長条件を確認する図](/images/articles/probation-period-lower-salary-checks-02.webp)

「試用期間3か月」と「4か月目の給与から増額」は、同じ意味とは限りません。起算日、締日、支払日を含め、いつ働いた分から金額が変わるのかを聞くと、認識の差を防げます。

| 確認点 | 質問例 |
| --- | --- |
| 切替日 | 何月何日の勤務分から本採用後の条件になりますか |
| 判断基準 | 期間の経過で切り替わりますか。別の審査がありますか |
| 通知方法 | 結果と給与条件はいつ、どの書面で案内されますか |
| 延長条件 | 延長があり得る場合、理由・期間・給与はどうなりますか |

試用期間と有期契約も混同しないようにしましょう。「最初は3か月契約」という説明なら、期間の定めの有無と、更新・登用の条件を別に確認します。2024年4月からの労働条件明示のルールには、有期契約の更新上限なども含まれます。

出典：[厚生労働省「2024年4月から労働条件明示のルールが変わります」](https://www.mhlw.go.jp/stf/newpage_32105.html)

## 試用期間だから最低賃金以下でよい、とはならない

本採用後より低い金額であることと、最低賃金を下回ることは別の問題です。最低賃金の減額特例は、使用者が都道府県労働局長の許可を受ける制度であり、試用期間という呼び名だけで当然に適用されるわけではありません。

出典：[滋賀労働局「最低賃金の減額の特例許可申請について」](https://jsite.mhlw.go.jp/shiga-roudoukyoku/hourei_seido_tetsuzuki/saitei_chingin/gengakutokurei.html)

月給を確認するときは、勤務時間や賃金の内訳も必要です。地域ごとの金額は改定されるため、古い求人票の数字だけで判断せず、勤務先に適用される最新の最低賃金を確認してください。

## 提示条件と回答を保存して承諾を判断する

![提示条件を並べて差を質問し回答を保存する手順](/images/articles/probation-period-lower-salary-checks-03.webp)

次はNARUの編集例です。

> 試用期間中と本採用後の給与条件について、基本給・手当・固定残業代の内訳と、切替日をご教示ください。また、本採用の判断基準、延長があり得る場合の期間と給与条件も、書面で確認できますか。

回答を受け取ったら、金額だけでなく「確定」「予定」「条件付き」のどれに当たるかも整理しましょう。「頑張れば上がる」という説明だけでは、生活費の見通しは立てにくいままです。

仕事内容や勤務地なども含めた判断は、[IT企業の内定承諾前の確認点](/articles/second-new-grad-it-offer-acceptance-checks)でまとめています。この記事では、試用期間中の給与から本採用後へ切り替わる条件に絞って確認しました。

給料が低いという一点だけで応募先を決めつける必要はありません。ただ、切替条件を聞いても明確な回答がないなら、承諾の判断に必要な情報が欠けている状態です。数字と条件をそろえてから選びましょう。
