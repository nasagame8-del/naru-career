「少し直すだけなので、同じ料金でお願いします」。Web制作やデザインの仕事で、こうした依頼が重なると、最初の見積もりでは想定していない作業が増えていきます。

無料か有料かを、修正回数だけで決めるのは難しいところです。まずは、合意した仕様に合わない部分を直す依頼なのか、発注後に新しい条件が加わったのかを照合してください。作業を始める前に、変更内容・費用・納期を文章でそろえることが、認識のずれを小さくします。

## 合意した仕様の修正と、新しい仕様の追加を区別する

![合意した仕様を満たすための修正と新しい仕様の追加を比較する図](/images/articles/contractor-unpaid-revisions-scope-01.webp)

例えば、指定されたリンク先を誤って実装した場合と、納品後に予約機能を追加してほしいと言われた場合では、依頼の理由が異なります。これはNARUの説明用の仮例です。どちらも「修正」と呼ばれていても、元の約束との関係は同じではありません。

| 確認点 | 照合する記録 |
| --- | --- |
| 最初に頼まれた内容 | 見積書、仕様書、発注メール |
| 納品・検収の基準 | 対象画面、動作、提出形式、検査方法 |
| 今回の変更 | 変更前後の内容、依頼日、理由 |
| 修正の取り決め | 対象範囲、回数、期限、追加料金の扱い |

「修正2回まで」と書かれていても、追加機能まで含むのかは別に確認が必要です。反対に、回数を超えたから自動的に請求できるとも限りません。合意した範囲と契約を基準に整理しましょう。

## 発注側の都合による無償のやり直しが問題になる場合

公正取引委員会のパンフレットは、受注者に責任がないのに、費用を負担せず内容の変更や受領後のやり直しをさせ、利益を不当に害する行為を説明しています。ソフトウェアを受領した後、検査基準を恣意的に厳しくして無償でやり直させた例も示されています。

出典：[公正取引委員会「フリーランス法パンフレット」17ページ](https://www.jftc.go.jp/file/flpamph.pdf)

この禁止行為には、受注者・発注者の要件と、1か月以上の業務委託という期間の条件があります。業務委託という名前だけで、すべての契約に同じ結論を当てはめることはできません。法の適用条件と、個別契約で請求できる金額も区別が必要です。

元の条件が書面に残っていない場合は、[業務委託の条件明示の確認点](/articles/contractor-no-written-contract)を参考に、発注時のやり取りから復元してください。

## 追加作業を始める前に、費用と納期をそろえる

![追加作業の前に変更内容、費用、納期を確認する図](/images/articles/contractor-unpaid-revisions-scope-02.webp)

作業を受けるか断るかを急ぐ前に、変更の差分を短く示すと、相手も判断しやすくなります。

| 項目 | 確認すること |
| --- | --- |
| 変更内容 | どの画面・機能・成果物を変えるか |
| 費用 | 元の報酬に含む範囲と、追加見積の対象 |
| 納期 | 追加作業による日程への影響 |
| 承諾 | 誰が変更と見積を了承するか |

次はNARUの編集例です。法的な請求通知ではありません。

> 今回のご依頼は、当初合意した○○に加えて△△を追加する内容と理解しています。変更範囲、追加費用、納期への影響を整理してご案内します。着手前に、対象範囲と条件をご確認いただけますか。

「追加費用がかかります」だけでは、何が追加なのか伝わりません。元の仕様と変更後を並べ、相手の了承を保存するところまでが実務上の確認です。

## 話がまとまらないときは変更の記録を残す

![仕様を照合し変更を記録して費用と納期を相談する手順](/images/articles/contractor-unpaid-revisions-scope-03.webp)

元の成果物、修正依頼、依頼日時、こちらの返答を保存してください。口頭の打ち合わせは、決まった内容をその後のメールで確認すると、振り返る材料になります。

案件自体が中止された場合は[発注キャンセル時の費用と日程の扱い](/articles/contractor-client-cancellation-costs)、確定した報酬が支払われない場合は[報酬未払いの確認手順](/articles/contractor-unpaid-fee-consultation)へ。修正範囲を決める話と、支払いを求める話では必要な記録が異なります。

無償で引き受け続けることも、依頼をすべて追加料金扱いにすることも、元の約束を確認しなければ判断できません。変更が小さいうちに、何が増えたのかを言葉にして共有することから始めましょう。
