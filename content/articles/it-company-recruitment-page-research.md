転職活動では、何社か候補を並べて「どこが一番いい会社か」を比較します。

でも、その比較は本当に公平なのでしょうか。

検索してすぐ採用ページが出る会社。求人媒体に情報が多い会社。職種別の募集要項が整理されている会社。そういう会社は、当然こちらの目に入りやすい。

逆に、会社は存在していても採用情報への導線が弱い会社は、比較のテーブルに乗る前に消えているかもしれません。

つまり私たちは「良い会社」を選んでいるつもりで、実際には「見つけやすい会社」の中から選んでいるだけではないか。

この疑問から、NARUでは厚生労働省「しょくばらぼ」の情報通信業データを起点に、企業ホームページURLが登録され、企業規模を分類できた対象から同一ホストの重複を整理した3,419社を調べました。

そこで見えたのは、想像以上に大きい“見つけやすさ”の差でした。

![採用情報の見つけやすさが候補形成に影響しうる構造を示した概念図](/images/articles/it-company-recruitment-page-research-01.webp)

NARU作成の概念図。実際の求職者行動を計測したものではありません。厚生労働省「しょくばらぼ」の2026年10月4日取得データと企業サイト探索結果をもとに問題設定を図示しています。[しょくばらぼ](https://shokuba.mhlw.go.jp/)

## 比較する前に、候補企業はすでにふるいにかけられている

企業研究というと、年収、仕事内容、研修、働き方、将来性などを比較するイメージがあります。

でも、それは候補企業を見つけた後の話です。

その一つ前には「その会社の採用情報にたどり着けるか」という段階があります。

ここで差があるなら、企業研究は完全なゼロ地点から始まっていません。

情報を見つけやすい会社ほど候補に残りやすく、見つけにくい会社ほど評価される前に落ちやすい。

今回の調査で、まずそこを確かめました。

## IT企業3,419社で、採用ページの“見つけやすさ”を比べた

元データは、2026年10月4日に取得した厚生労働省「しょくばらぼ」の全件CSVです。

全152,392行のうち、業種が情報通信業の企業は8,118社でした。

その中から、企業ホームページURLがあり、企業規模を分類でき、同一ホストの重複を整理できた3,419社を対象にしました。

企業公式ホームページを起点に、主に次の導線を探索しています。

- 「採用」「採用情報」
- 「Recruit」「Careers」「Jobs」
- 公式ホームページから直接リンクされた採用専用サイト
- 公式ホームページから直接リンクされたATS
- robots.txtやサイトマップから確認できる採用関連URL

第三者求人媒体を横断クロールしたり、403や429、robots.txtの拒否を回避したりはしていません。

出典：
- [厚生労働省 職場情報総合サイト「しょくばらぼ」](https://shokuba.mhlw.go.jp/)
- [しょくばらぼ CSV一括ダウンロード](https://shokuba.mhlw.go.jp/shokuba/utilize/utilize010.do)

## 小さい会社ほど、採用情報を見つけにくい傾向があった

企業規模ごとに、採用関連ページをhighまたはmedium判定できた割合を並べるとこうなりました。

| 従業員規模 | 対象企業 | high/mediumで発見 | 発見率 |
| --- | ---: | ---: | ---: |
| 1〜4人 | 358社 | 135社 | 37.7% |
| 5〜9人 | 299社 | 152社 | 50.8% |
| 10〜29人 | 617社 | 423社 | 68.6% |
| 30〜99人 | 709社 | 554社 | 78.1% |
| 100〜299人 | 788社 | 671社 | 85.2% |
| 300〜999人 | 439社 | 383社 | 87.2% |
| 1,000人以上 | 209社 | 177社 | 84.7% |

1〜4人企業では37.7%。

一方、300〜999人企業では87.2%でした。

約50ポイント違います。

もちろん、これは「小さい会社は採用していない」という数字ではありません。

測っているのは、今回の探索条件で公式サイトから採用関連ページ候補を見つけられた割合です。

それでも、転職活動の入口でこれだけ差があるなら、候補企業を探す段階から規模による偏りが入りうることは無視できません。

この差だけで、実際の求職者が小規模企業を候補から外しているとまでは言えません。

ただ、企業を比較する前段階で採用情報への到達しやすさに差がある以上、「見つけやすさ」が候補形成に影響する可能性はあります。これが今回の調査で一番気になった点です。

## 意外だったのは、小さい会社のホームページ自体は普通に見つかっていたこと

ここで最初に考えたのは、「小さい会社はそもそもホームページが古い、あるいは取得できないからでは？」ということでした。

しかし、実際の数字は少し違いました。

企業ホームページ自体の取得成功率を見ると、

| 従業員規模 | ホームページ取得成功率 |
| --- | ---: |
| 1〜4人 | 91.9% |
| 5〜9人 | 93.7% |
| 10〜29人 | 89.8% |
| 30〜99人 | 91.5% |
| 100〜299人 | 92.6% |
| 300〜999人 | 91.3% |
| 1,000人以上 | 87.6% |

1〜4人企業でも91.9%はホームページ本文を取得できています。

それなのに、採用関連ページ候補をhigh/medium判定できたのは37.7%でした。

つまり少なくとも今回のデータでは、「小さい会社はWeb上に存在しないから見つからない」という単純な話ではありませんでした。

ホームページにはたどり着ける。でも、採用情報への導線は見つけにくい。

この差は、企業を見る側にとってかなり重要です。

サイトがあることと、採用情報を見つけやすいことは別だからです。

## さらに、しょくばらぼの「採用ページURL」欄は2.4%しか埋まっていなかった

もう一つ大きな差がありました。

しょくばらぼの情報通信業8,118社のうち、「採用ページ」欄にURLが入っていたのは196社でした。

2.4%です。

| 項目 | 件数 |
| --- | ---: |
| 情報通信業 | 8,118社 |
| 企業ホームページURLあり | 3,513社 |
| 採用ページURLあり | 196社 |
| 採用ページURL記載率 | 2.4% |

では本当に、ほとんどの企業に採用ページがないのでしょうか。

3,419社を企業公式ホームページ起点で自動探索すると、highまたはmedium判定の採用関連ページ候補は2,495社で見つかりました。今回の探索条件では73.0%です。

さらに、この3,419社のうち、しょくばらぼ側に採用ページURLが登録されていた企業は174社でしたが、URL登録のなかった企業から新たに2,348社分の候補を発見しています。

ここで見えてくるのは、同じ企業でも「どこから探すか」で見える景色が大きく変わることです。

公的DBにURLがない。

検索結果で採用ページが目立たない。

それだけで「採用していなさそう」と判断すると、実際には存在する採用導線まで見落とす可能性があります。

ただし、2,495社という数字は自動Discoveryのhigh/medium判定です。後工程では、日本IBMのケーススタディページをmedium判定していた既知の誤検出も確認しています。そのため73.0%を「真の採用ページ保有率」とは扱っていません。

## 結論は、「良い会社を見抜く力」より先に「候補を落としすぎない力」が必要ということ

調査前は、「採用情報が少ない会社は企業研究しづらい」という程度の話だと思っていました。

でも3,419社を見ると、もう少し根本的でした。

企業を評価する前に、情報の見つけやすさで候補企業そのものが偏る可能性があります。

そして、その見つけやすさは企業規模によってかなり違いました。

ここで危ないのは、

「情報が多い会社＝良い会社」

「採用サイトが整っている会社＝自分に合う会社」

「見つからない会社＝採用していない会社」

と無意識に置き換えてしまうことです。

今回のデータは、そのどれも証明していません。

むしろ分かったのは、会社を評価する軸と、会社を見つけやすいかどうかは別物として扱った方がいいということです。

これが今回の調査で一番意外だった結論です。

## 企業研究を「見つける」と「評価する」の2段階に分ける

第二新卒の企業研究では、最初からすべてを評価しようとせず、二段階に分けると考えやすくなります。

### 1. まず候補を見つける

この段階では情報量の少なさだけで会社を落としません。

企業公式サイトに加えて、

- 採用情報
- Recruit / Careers
- キャリア採用
- 中途採用
- 公式ATS
- 求人媒体
- ハローワーク
- 紹介会社から受け取った求人

など、入口を分けて探します。

公的DBの空欄も「なし」ではなく「未記載」として扱います。

### 2. 見つけた後に会社を評価する

評価するときは、採用サイトの豪華さではなく、自分が応募する職種の情報を見ます。

確認したいのは、

- 実際の仕事内容
- 必須条件と歓迎条件
- 雇用形態
- 給与・固定残業代
- 勤務地
- 教育とレビュー担当
- 配属先
- 労働条件

です。

[IT企業の企業研究で見るポイント](/articles/second-new-grad-it-company-research)では、サービス、顧客、収益、配属先を分けて確認する方法を整理しています。

未経験求人なら、[未経験IT求人の研修制度を見るポイント](/articles/it-training-program-job-checklist)も合わせて確認してください。

## 「検索上手な会社」だけで転職先を決めない

採用ページが見つけやすいこと自体は悪いことではありません。

求職者に必要な情報を整理し、分かりやすく公開している企業は、企業研究しやすいのも事実です。

ただし、それを会社の良し悪しと同じ指標にしてしまうと、比較する前から候補が偏ります。

今回の3,419社調査から示唆されたのは、転職活動では「企業を比較する段階」だけでなく、その手前の「企業を見つける段階」にも偏りが入りうるということでした。

私たちは「一番良い会社」を選んでいるのか。

それとも、最初から「見つけられた会社」の中で一番良さそうな会社を選んでいるのか。

企業研究を始めるとき、一度この違いを意識しておいてもいいと思います。

## 今回の調査の範囲と限界

今回の記事は、2026年10月4日に取得した厚生労働省「しょくばらぼ」の全件CSVを起点にしたNARU独自調査です。

対象は日本の全IT企業ではありません。

しょくばらぼで業種が情報通信業となっている8,118社を母集団とし、その中から企業ホームページURLがあり、企業規模を分類でき、同一ホストの重複を整理した3,419社をDiscovery対象にしています。

また、URL探索には自動処理を含むため、誤検出と取りこぼしがあります。

highまたはmedium判定2,495社という数字は今回の探索ルール上の結果であり、日本のIT企業全体の「採用ページ保有率」ではありません。

逆に、lowまたは見つからなかった企業についても、「採用ページがない」「採用していない」とは判断できません。

今回の調査から言えるのは、企業規模によって採用関連ページの見つけやすさに大きな差があり、候補企業を探す段階そのものに偏りが入りうる、というところまでです。
