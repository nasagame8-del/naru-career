第二新卒でIT企業を調べていると、会社概要は見つかるのに「採用情報がどこにあるのか分からない」会社があります。

そこでNARUでは、厚生労働省の職場情報総合サイト「しょくばらぼ」の全件CSVを起点に、情報通信業の企業を抽出し、企業公式ホームページから採用関連ページを探しました。

先に重要な点をまとめると、しょくばらぼの「採用ページ」欄だけを見るとURLが入っているのは情報通信業8,118社のうち196社、2.4%でした。一方、企業ホームページを起点に探索した3,419社では、採用関連ページとしてhighまたはmedium判定したURL候補が2,495社で見つかりました。

ただし、この73.0%を「IT企業の73%が確実に採用ページを持つ」とは書きません。自動探索には既知の誤検出があり、母集団も日本の全IT企業ではなく、しょくばらぼ掲載企業のうち企業ホームページなどの条件を満たした企業だからです。

この記事では数字を企業ランキングに使うのではなく、第二新卒が企業研究をするときに「採用ページが見つからない」をどう扱うべきかを整理します。

![公的DBと企業公式サイトを分けて採用情報を探す図](/images/articles/it-company-recruitment-page-research-01.webp)

## しょくばらぼの採用ページ欄だけでは拾えない

しょくばらぼは、企業の働き方や採用状況などの職場情報を検索・比較できる厚生労働省のサイトです。

出典：
- [厚生労働省 職場情報総合サイト「しょくばらぼ」](https://shokuba.mhlw.go.jp/)
- [しょくばらぼ CSV一括ダウンロード](https://shokuba.mhlw.go.jp/shokuba/utilize/utilize010.do)

2026年10月4日に取得した全件CSVには152,392行、634列があり、そのうち業種が情報通信業の行は8,118社でした。

この8,118社で「採用ページ」欄にURLが入っていたのは196社です。

| 項目 | 件数 |
| --- | ---: |
| 情報通信業 | 8,118社 |
| 企業ホームページURLあり | 3,513社 |
| 採用ページURLあり | 196社 |
| 採用ページURL記載率 | 2.4% |

ここで注意したいのは、空欄は「採用ページが存在しない」という意味ではないことです。

しょくばらぼは企業の職場情報を横断して見るための入口であり、各社の採用サイトを完全に収録した求人検索サービスではありません。厚生労働省も、しょくばらぼを勤務実態や採用状況などの職場情報を検索・比較するサイトとして案内しています。

だから、採用ページ欄にURLがない会社をその時点で候補から外すのは早すぎます。

## 3,419社は企業公式ホームページから探し直した

NARUでは、企業ホームページURLがある会社から、企業規模の区分ができ、同一ホストの重複を整理できた3,419社を対象に採用関連ページを探索しました。

探したのは、主に次のような導線です。

- 公式ホームページの「採用」「採用情報」
- 「Recruit」「Careers」「Jobs」
- 公式ホームページから直接リンクされた採用専用サイト
- 公式ホームページから直接リンクされたATS
- robots.txtやサイトマップから確認できる採用関連URL

逆に、Google検索結果を大量取得したり、Indeedなど第三者求人媒体を横断クロールしたりはしていません。robots.txtで明示的に拒否されたページや403、429も突破していません。

その結果、3,419社のうちホームページ本文まで取得できたのは3,126社。採用関連ページとしてhighまたはmedium判定したURL候補は2,495社でした。

| Discovery結果 | 企業数 |
| --- | ---: |
| high | 2,354社 |
| medium | 141社 |
| low | 172社 |
| 見つからず | 752社 |
| 合計 | 3,419社 |

highとmediumを合わせると2,495社、全体の73.0%です。

ただし、ここには自動判定の限界があります。後工程の確認で、日本IBMについて採用ページではないケーススタディページをmedium判定していた例を確認しました。そのため、この記事では2,495社を「自動Discoveryで採用したURL候補数」として扱い、真の保有率とは区別します。

## 国のDBにURLがなくても、公式サイトには採用導線がある

今回の3,419社のうち、しょくばらぼ側に採用ページURLが入っていた企業は174社でした。

それに対し、企業ホームページを起点にしたDiscoveryでは、しょくばらぼの採用ページ欄にURLがなかった企業からも2,348社分の採用関連URL候補を新たに見つけています。

ここから言えるのは、「公的DBに採用ページURLがない」と「企業に採用情報がない」は別だということです。

公的DBは職場情報を比較するのに強く、企業公式サイトは現在の募集導線や会社独自の説明を確認するのに向いています。どちらか一つで企業研究を完結させるより、役割を分けて見る方が安全です。

[IT企業の企業研究で見るポイント](/articles/second-new-grad-it-company-research)でも、サービス、顧客、収益、配属先などを複数の資料から確認する方法を整理しています。

## 第二新卒が採用ページを探す順番

応募したい会社が決まっているなら、次の順番で探すと迷いにくくなります。

### 1. 企業公式ホームページを開く

検索結果に出てくる求人媒体ではなく、まず会社の公式ドメインを確認します。

ヘッダーやフッターに「採用情報」「Recruit」「Careers」があれば、そこから進みます。

### 2. 新卒と中途の入口を分ける

採用ページが見つかっても、新卒採用だけのページであることがあります。

第二新卒の場合は、

- キャリア採用
- 中途採用
- 第二新卒
- 既卒
- 未経験
- ポテンシャル採用

といった入口があるかを確認します。

ただし、これらの語がページにあるだけで応募可能とは限りません。最終的には自分が応募する職種の募集要項を確認します。

### 3. 実際の求人票まで進む

採用トップページは会社の考え方を知るには便利ですが、雇用条件の確認は求人票が中心です。

仕事内容、必須条件、雇用形態、勤務地、給与などは職種ごとのページで確認してください。

[未経験IT求人の研修制度を見るポイント](/articles/it-training-program-job-checklist)でも、会社全体の制度と自分が応募する職種の条件を分けて見る方法を整理しています。

## 採用ページが見つからなくても「募集なし」とは限らない

今回のDiscoveryでも752社ではhighまたはmediumの採用ページ候補を採用できませんでした。

しかし、その752社がすべて採用をしていないとは判断できません。

理由は複数あります。

- 公式ホームページ自体を正常取得できない
- 採用情報がJavaScriptで描画される
- 求人媒体だけで募集している
- ハローワークなど別経路を使っている
- 採用ページの名称やURL構造が探索ルールと異なる
- 現在は募集停止中

実際、3,419社のうち企業ホームページ取得に失敗した企業は293社あり、DNS、404、403、TLS証明書、タイムアウトなど理由もさまざまでした。

したがって「見つからない」という観測結果を、そのまま「存在しない」に変換しないことが重要です。

## 企業研究では資料ごとの役割を分ける

第二新卒の企業研究では、次の三つを別々の資料として見ると整理しやすくなります。

| 資料 | 主に確認すること |
| --- | --- |
| しょくばらぼ | 職場情報、制度、採用・定着関連の開示 |
| 企業公式サイト | 事業、組織、採用方針、公式の採用導線 |
| 求人票 | 応募職種の仕事内容、条件、勤務地、給与 |

エージェントから求人を紹介された場合も、紹介された求人だけで終わらせず企業公式サイトを確認できます。[エージェント紹介と自己応募の違い](/articles/agent-referral-vs-self-apply)も合わせて確認してください。

## 今回の調査の範囲と限界

今回の記事は、2026年10月4日に取得したしょくばらぼCSVを起点にしたNARU独自調査です。

対象は日本の全IT企業ではありません。しょくばらぼで業種が情報通信業となっている8,118社を母集団とし、その中から企業ホームページや企業規模の条件を満たし、同一ホストの重複を整理した3,419社をDiscovery対象にしています。

また、URL探索は自動処理を含むため誤検出と取りこぼしがあります。highまたはmedium判定2,495社という数字は、自動判定結果の監査値であり、統計的な「日本のIT企業の採用ページ保有率」ではありません。

一方で、しょくばらぼの採用ページURL欄だけを見るより、企業公式ホームページまで確認した方が採用導線を見つけられる企業が大幅に増えたことは、今回のデータで確認できました。

企業研究では、空欄を結論にせず、次の一次情報へ進む。その一手間が、応募候補を狭めすぎないために重要です。
