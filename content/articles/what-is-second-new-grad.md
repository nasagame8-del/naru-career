==第二新卒の対象は、3年目の3月で全国一律に終了するわけではありません。== 「卒業後おおむね3年以内」は目安ですが、実際に応募できるかは求人ごとの条件で確認します。卒業年月、就業経験、応募時・入社時のどちらを基準にするかを分けて見ましょう。

## 第二新卒の定義と、新卒枠の応募機会は区別する

[リクルートエージェントの採用実務解説](https://www.r-agent.com/business/knowhow/article/3870/)では、第二新卒は卒業後に就職し、3年以内に転職を考える人材を指す言葉として説明される一方、明確な定義はなく企業によって捉え方が異なるとしています。

また、[岩手労働局の新卒採用案内](https://jsite.mhlw.go.jp/iwate-roudoukyoku/roudoukyoku/gyoumu_naiyou/antei/shinsotsu_bosyu.html)は、卒業・修了後少なくとも3年以内の既卒者への応募機会の確保などを企業へ求めています。これは新卒枠の応募機会に関する案内であり、すべての会社の第二新卒枠に共通する合否条件ではありません。

企業の募集要項で「卒業後年数」「就業経験」「入社日」の各条件を照合する必要があります。第二新卒歓迎という見出しだけで、すべての条件を満たすと判断しないようにしましょう。

## 第二新卒は3年目の3月まで？4月で対象外とは限らない

社会人の年次と、卒業後の経過年数は同じとは限りません。卒業してから就職まで期間が空いた場合や、途中の月に入社した場合は、自分の「3年目」だけで応募資格を判断できません。

| 募集要項の記載 | 確認すること |
| --- | --- |
| 卒業後3年以内 | 卒業年月をどう数えるか、判定日はいつか |
| 社会人経験3年未満 | 対象となる就業経験と、入社時までを数えるか |
| 第二新卒歓迎 | 別に必須条件や指定の卒業年度があるか |
| 特定年の4月入社 | その入社日に応募資格を満たす必要があるか |

たとえば2024年3月卒で、2027年4月入社を希望するという想定なら、「3年目のうちに応募すれば大丈夫」とも「4月入社だから応募不可」とも決めつけられません。募集側が指定する卒業年度と基準日を確認してください。この例は年数の確認方法を示すもので、応募資格の判定ではありません。

### 応募時と入社時の基準が不明なら、卒業年月を添えて質問する

> 2024年3月に卒業し、同年4月から就業しています。2027年4月入社を希望していますが、募集要項の「卒業後3年以内」は応募時点と入社時点のどちらで判定されますか。今回の募集に応募可能か、ご確認いただけますでしょうか。

日付や経歴は自分の状況へ置き換えます。条件に合わない場合は、同じ企業の別の採用枠や、経験不問の中途求人も調べられます。

## 第二新卒に当てはまる年齢・年数は、卒業年月と経歴から確認する

年齢だけで第二新卒かを判定することはできません。進学、留学、就業前の期間などによって、同じ年齢でも卒業後年数や経験が異なるからです。

| 自分の情報 | 求人票と照合する項目 |
| --- | --- |
| 最終学歴と卒業年月 | 対象となる学歴、指定の卒業年度 |
| 就職・退職の年月 | 就業経験の条件と計算基準 |
| 経験した仕事 | 必須経験、経験不問の対象範囲 |
| 入社可能日 | 指定日と相談の可否 |

「第二新卒の枠から外れたら転職できない」という意味でもありません。中途採用の中にも経験不問の求人があります。呼び方だけで探す範囲を狭めず、仕事内容と必須条件を読んで判断しましょう。

公的な相談先として、[新卒応援ハローワーク](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000132220.html)は卒業後おおむね3年以内の方などを支援しています。ただし、相談窓口の利用対象と、応募企業の採用条件は別です。

## 第二新卒と既卒・中途の違い

呼び方には企業やサービスによる違いがあります。以下は求人を読み分けるための整理であり、法的に統一された分類ではありません。

| 区分 | 読み分けの手がかり |
| --- | --- |
| 新卒 | 卒業予定者が中心。既卒者を受け付ける条件があるかも確認 |
| 既卒 | すでに学校を卒業した人。就業経験の扱いは募集条件で確認 |
| 第二新卒 | 卒業後に就職し、短い就業経験を持つ人を指すことがある |
| 中途 | 既卒の採用を広く扱う。即戦力求人だけでなく経験不問の求人もある |

一方で「早期離職のリスク」を懸念する企業もあるため、面接では「なぜ短期間で辞めたのか」「次は長く働く意志があるか」を説得力を持って伝える必要があります。転職を考えるきっかけは人それぞれですが、[昇進できない理由が上司の主観だった](/articles/promotion-blocked-by-boss)り、[評価に納得がいかない](/articles/unfair-evaluation-not-spoiled)といった構造的な問題が背景にあるケースも少なくありません。



## 第二新卒の選考は、呼び方より応募職種の条件を見る

第二新卒歓迎でも、必要な経験や知識は求人によって異なります。育成を前提とした採用なのか、特定の業務経験が必要なのかを募集要項で確かめましょう。社会人経験があるだけで研修が不要になるとも、新卒と同じ研修を受けられるとも限りません。

準備では、これまでの担当業務と応募職種で生かせる経験を対応させます。「第二新卒なので学びたい」だけで終えず、現職で取り組んだことや、自分で始めた学習を具体的に説明できるようにしておくと、応募先への質問も整理しやすくなります。

## 第二新卒の転職活動で押さえるべきポイント

面接準備では、辞めたい理由、次に担当したい仕事、その会社へ応募する理由を別々に書き出します。そのうえで、矛盾なく説明できるかを読み直しましょう。これは編集部の準備案であり、選考で評価される項目を一律に定めるものではありません。

| 準備すること | 書き出す内容 |
| --- | --- |
| これまでの経験 | 担当業務、工夫したこと、確認できる成果 |
| 転職の目的 | 次の環境で変えたいこと、実現したい仕事 |
| 応募先とのつながり | 経験を生かせる点と、新しく学ぶ必要がある点 |
| 条件の不明点 | 応募資格、入社日、仕事内容、研修の対象 |

## 応募資格が曖昧なら、企業や相談窓口へ確認する

応募先の資格条件を確定できるのは募集側です。紹介サービス経由なら担当者に確認を依頼でき、直接応募なら指定の採用窓口へ問い合わせられます。

応募の進め方や書類に迷ったときは、新卒応援ハローワークなどの公的な窓口や、転職支援サービスへの相談も選択肢になります。窓口ごとに利用対象や支援範囲を確認し、自分に必要な支援が受けられるかを尋ねましょう。

## よくある質問

### 第二新卒は3年目の3月までですか？

全国一律の終了日はありません。卒業後年数や就業経験、応募時と入社時のどちらを基準にするかを、求人ごとに確認してください。

### 4月で社会人4年目になると応募できませんか？

年次だけでは判断できません。対象の卒業年度や経験年数を指定した求人もあるため、卒業年月と就業開始年月を添えて採用担当者へ確認しましょう。

### 第二新卒は何歳までですか？

年齢だけで一律には決まりません。卒業後おおむね3年以内などを目安に説明されますが、応募先の募集要項が判断の出発点です。

### 第二新卒枠に入らなければ未経験職種へ転職できませんか？

第二新卒以外にも経験不問の求人はあります。職種ごとの必須条件を確認し、応募できる募集を探してください。
